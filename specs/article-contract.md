# 記事の完了基準（二値判定のみ）

「寸法で選ぶ」の記事が公開してよい状態か。**できた／できていないが機械的に判定できる項目だけ**を置く。
主観的な良し悪しは `article-rubric.md`（段階評価）で、**落第の判定には使わない**。

⚠️ **1件でも不合格なら落第。** 段階評価の高さで買い戻せない。

⚠️ **このファイルを書き換えてよいのは利用者とメインセッションだけ。**
書き手も検証者も基準そのものを変えない（変えられると「落ちる検査を消して全部合格」ができる）。

---

## 検証は3層。上から順に、通ったものだけ下へ回す

```
① ビルド        … 数秒。落ちたら誰かに見せる前に書き手が直す
② この契約      … 1件でも不合格なら落第
③ ルーブリック  … ①②を通ったものだけ。落第には使わない
```

## ★ ビルドがすでに落としているものは、ここに書かない

`site/build.mjs` が例外を投げて止めるものは**二重化しない**。判定が増えないため。

| ビルドが落とすもの | 実装 |
|---|---|
| front matter の5項目＋category | `readFrontMatter` ／ カテゴリ照合 |
| カードの数字とその商品の表の行の不一致 | `assertCardNumbers` |
| 日本語の太字が約物で壊れる形 | `assertNoRawEmphasis` |
| eyecatch と同じ画像が本文にも残る | eyecatch 重複チェック |
| 引用の直後に空行がなく本文が飲み込まれる | `assertNoLazyBlockquote` |
| `[[LINK:...]]` の検索語が空 | `resolveLinks` |
| 図版の数値が元図と食い違う／見出しがはみ出す／文字が重なる | `tools/figures/build.py` |

**契約が埋めるのは「ビルドが見ていない穴」だけ。**

---

## 契約（すべて二値）

### A. 機械で回すもの（`/article-check` が実行する。`Bash` が要る）

| # | 判定 | 確かめ方 |
|---|---|---|
| A1 | ビルドが成功する | `npm run build --prefix site` の終了コードが 0 |
| A2 | 価格・在庫・送料に触れていない | `価格` `在庫` `送料` `セール` `割引` `安い` `¥` を全文検索して0件。`円` もヒットを1件ずつ見る（**`楕円` `円筒` `円形` は誤検出**） |
| A3 | 最初のアフィリエイトリンクが本文の20%以内 | `python tools/check-link-position.py` に当該記事が超過として出ない |
| A4 | 図版が PowerPoint 版である | 参照している画像が `tools/figures/figures.py` の `ORDER` にある |

### B. 読んで判定するもの（`/article-check` が人／メインセッションの目で見る）

| # | 判定 | 確かめ方 |
|---|---|---|
| B1 | 計算値を「実測」と書いていない | 「実測」を全文検索し、各出現が本当に測った値か見る |
| B2 | 未検証の主張に `未検証` と明記されている | 一次情報で確認できなかった記述に印があるか |
| B3 | 表の計算値が独立に再現できる | 表の計算値を**1つ以上選んで自分で計算し直し**、一致する |

### C. `source-verifier` に投げるもの（一次情報の照合）

| # | 判定 |
|---|---|
| C1 | 本文の数値が、本文に書かれた出典URLの記載と**文字列で一致**する |
| C2 | 出典URLがすべてメーカー公式または公的機関。**通販サイト・まとめ記事が0件** |
| C3 | 公式に書かれていないことを、書かれているように書いていない |

⚠️ **`source-verifier` は `Bash` を持っていない。** だから A は投げられない。**役割を混ぜないこと。**
⚠️ **書き手の申告を根拠にしない。** 「ビルドを通しました」は再実行して確かめる。

---

## 不合格の書き方

**不合格にする項目は「ファイル名:行番号」と該当箇所の引用を必ず出す。**
出せないものは不合格にしない。**これが「二値で判定できる」の担保**であって、
理由を書かずに「怪しい」で落とすことは認めない。

⚠️ A2・B1・B2・B3 は、検索そのものは機械的だが**ヒット1件ごとの判定に読解が要る**。
だからこそ、どの行のどの表現が引っかかったのかを必ず示す。
