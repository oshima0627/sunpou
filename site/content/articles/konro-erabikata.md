カセットコンロの仕様表でいちばん目に入るのは「**目安として9号土鍋まで**」という一行ですが、これは号数の目安であって、寸法ではありません。

このサイトでは、メーカーが公表している寸法から計算した記事を積んできました。
**その結果を1枚にまとめたのがこのページです。** 使いたい鍋と、使いたい時間から逆に引けます。

## まず、「9号まで」は寸法ではありません

ここがこのページの前提です。**土鍋の号数に、決まった寸法はありません。**

銀峯陶器の同じ9号でも、取手込みの幅は**31〜32.5cm**まで動きます。詳しくは[カセットコンロに9号土鍋は乗る？](/cassette-konro/donabe-nangou/)にまとめました。

| 号数 | 号数×3cm | 実際の口径 | **実際の幅（取手込）** |
|---|---|---|---|
| 6号 | 18cm | 18.5〜19cm | **21〜22cm** |
| 7号 | 21cm | 22cm | **24〜26.5cm** |
| 8号 | 24cm | 24〜25cm | **27〜29.5cm** |
| 9号 | 27cm | 28〜28.5cm | **31〜32.5cm** |
| 10号 | 30cm | 31cm | **34〜36cm** |

銀峯陶器の18製品の実寸です。**取手込みの幅は号数×3cmより4〜6cm大きくなります。**

### ミニの「内径20cmまで」を号数に直すと6号まで

銀峯陶器の口径に当てはめます。**当サイトの計算です。**

| 土鍋 | 口径 | 内径20cmに入るか |
|---|---|---|
| 5.5号 墨貫入 | 17.0cm | **入る** |
| 6号 菊花／菊花 深型／花三島／墨貫入（4製品） | 18.5〜19.0cm | **4製品とも入る** |
| **7号 菊花** | **22.0cm** | **入らない** |

**ミニは実質6号までです。** 7号は口径がいちばん小さい製品でも22.0cmで、2.0cm足りません。

## 卓上に要るのは「コンロの幅」ではなく、大きいほうの幅です

**鍋がコンロよりはみ出すことは普通に起こります。** 場所を決めるのは、コンロと鍋の大きいほうです。

**9号土鍋でいちばん幅のある墨貫入（32.5cm）を置いたとき**です。**当サイトの計算です。**

| 機種 | 本体幅 | 9号（最大32.5cm）との差 | 卓上に要る幅 |
|---|---|---|---|
| **スリム** | 32.8cm | **+0.3cm** | 32.8cm |
| スマート／ウィンドシールド | 33.4cm | +0.9cm | 33.4cm |
| 達人スリムV／達人スリムβ | 33.5cm | +1.0cm | 33.5cm |
| BO— | 33.7cm | +1.2cm | 33.7cm |
| アモルフォ プレミアム | 35.5cm | +3.0cm | 35.5cm |
| 雅SLIM | 35.85cm | +3.35cm | 35.85cm |
| **極** | 39.1cm | **+6.6cm** | 39.1cm |

**同じ「9号まで」でも、卓上に要る幅は32.8cmから39.1cmまで開きます。**

⚠️ **10号は事情が違います。** 「10号まで」のエコプレミアムIIIは本体幅33.4cmなので、10号の土鍋のほうが大きくなります。花三島10号（34.0cm）で**0.6cm**、墨貫入10号（36.0cm）で**2.6cm**はみ出します。
**はみ出す＝使えない、ではありません。** メーカーが言っているのは五徳に乗るかどうかです。

## ボンベ1本で何分、6本で何時間

イワタニは連続燃焼時間を「強火連続でボンベ1本を使い切るまでの実測値」として公表しています。

**農林水産省は家庭備蓄の目安を「1人1週間あたりカセットボンベ6本」としています**（[カセットボンベは何本備える？](/cassette-konro/bombe-honsuu/)）。**6本ぶんを強火の連続に直しました。当サイトの計算です。**

| 機種 | ボンベ1本 | **6本ぶん** |
|---|---|---|
| ミニ（通常ボンベ使用時） | 112分 | **11.2時間** |
| スマート／ウィンドシールド | 78分 | 7.8時間 |
| 極 | 74分 | 7.4時間 |
| エコプレミアムIII／アモルフォ プレミアム | 72分 | 7.2時間 |
| スリム／達人スリムβ／雅SLIM | 70分 | 7.0時間 |
| 達人スリムV | 68分 | 6.8時間 |
| **BO—** | **55分** | **5.5時間** |

**同じ6本でも、機種によって5.5時間と11.2時間に分かれます。** 倍以上の差です。

⚠️ **強火の連続での話です。** 弱火や中火での時間はメーカーが公表していません。
⚠️ **気温の条件は20〜25℃です。** それ以外の気温での値は公表されていません。

**ミニはボンベを2種類使えます。** ジュニア（120g）だと56分、通常（250g）だと112分です。[[LINK:イワタニ カセットガス 3本組::通常のカセットガスをAmazonで見る]]

## 火力から読めるのは、ガスの減り方だけです

**最大発熱量とガス消費量は、ほぼぴったり連動します。** 順位相関は **+0.998** でした。

**ところが、火力から次の2つは読めません。**

```
火力 → 乗る鍋の大きさ    … 関係なし（最小2.9kWの機種が唯一の「10号まで」）
火力 → ボンベ1本でもつ時間 … ほぼ関係なし（順位相関 −0.33、ミニを除くと −0.10）
```

いちばん分かりやすい例です。

```
スマート        3.5kW ／ 254g/h → 78分（最長）
エコプレミアムIII 2.9kW ／ 210g/h → 72分
```

**火力も消費量も上のスマートのほうが、6分長くもちます。** 理由は[カセットボンベ1本で何分使える？](/cassette-konro/nenshou-jikan/)にあります。連続燃焼時間は「250g ÷ 消費量」より**1分から19分**上振れし、その上振れ幅が機種ごとにばらつくためです。

**つまり、火力・鍋の大きさ・もつ時間は、仕様表で別々に見ることになります。**

## 買う前に測る数字

```
① 手持ちの土鍋の「幅（取手込）」 … 号数ではなくこの値が置き場所を決める
                                 9号＝31〜32.5cm ／ 10号＝34〜36cm
② 卓上で使える幅               … コンロと鍋の大きいほう。9号なら32.8〜39.1cm
③ 連続燃焼時間                … 火力からは読めない。仕様表の分数を直接見る
④ 商品重量                    … 1.0〜2.2kg。出し入れの頻度で効く
```

**いちばん確実なのは、買う前に手持ちの土鍋の取手込みの幅を測ることです。**

## この記事で扱っていないこと

- **五徳の径** — 11機種のどれも公表していません。ミニだけが鍋の内径で書いています
- **土鍋の鍋底の径** — どのシリーズでも非公表です。「鍋底16cm以上」を満たすか判定できません
- **五徳に安定して乗るか** — 上の2つが分からないため判定できません。メーカーの指示に従ってください
- **弱火・中火での燃焼時間** — 公表は強火連続のみです
- **20〜25℃以外の気温** — 公表条件は20〜25℃だけです
- **銀峯陶器以外の土鍋** — 他社の同じ号数が同じ寸法とは限りません（未確認）
- **イワタニ以外のカセットコンロ** — この記事は岩谷産業の製品だけを見ています
- **火力の体感・保温性・味** — 寸法と時間の話しかしていません
- **価格** — 扱いません
