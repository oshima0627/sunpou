麦茶を2Lのまま持っていきたい。スポーツドリンクを2Lで買って冷やしたい。
そう思ってクーラーボックスの容量を見ても、**「2Lが立つかどうか」はどこにも書いてありません。**

メーカーが公表している内寸から判定しました。先に結論です。

## 結論：2Lが立つのは深さ310mmから。10〜25Lではまず立ちません

調べた8製品のうち、**2Lボトルが立てて入ったのは40Lの1製品だけ**でした。

| 製品 | 容量 | 内寸の深さ | 2Lは立つ？ |
|---|---|---|---|
| ダイワ クールラインα3 S1000X [[LINK:ダイワ クールラインα3 S1000X]] | 10L | 220mm | ✗ |
| ダイワ クールラインα3 S1500 [[LINK:ダイワ クールラインα3 S1500]] | 15L | 230mm | ✗ |
| ダイワ クールラインα3 S2000 [[LINK:ダイワ クールラインα3 S2000]] | 20L | 220mm | ✗ |
| ダイワ クールラインα3 S2500 [[LINK:ダイワ クールラインα3 S2500]] | 25L | 255mm | ✗ |
| ロゴス ハイパー氷点下クーラーL [[LINK:ロゴス ハイパー氷点下クーラーL]] | 20L | 240mm | ✗ |
| アイリスオーヤマ HUGEL 真空断熱 15L [[LINK:アイリスオーヤマ HUGEL 15L]] | 15L | 243mm | ✗ |
| アイリスオーヤマ HUGEL 真空断熱 20L [[LINK:アイリスオーヤマ HUGEL 20L]] | 20L | 240mm | ✗ |
| **アイリスオーヤマ HUGEL 真空断熱 40L** [[LINK:アイリスオーヤマ HUGEL 40L]] | 40L | **310mm** | **○** |

2Lボトルの全高は **305〜306mm**。40Lの310mmでも**余裕は4mm**しかありません。

なお、その後さらに大型モデルまで広げて調べたところ、[26製品のうち2Lが立つのは3つだけ](/coolerbox/erabikata/)でした（この40Lに加え、ダイワ タフトランク4300 と トランクマスターHD III 8000）。

⚠️ **ただしこれは日本の釣り系メーカー中心の話でした。**
[コールマンは26Lクラスでも内寸の深さが350mmあり、7製品中6つで2Lが立ちます](/coolerbox/coleman-uchinori/)。
**2Lを立てたいならコールマンを見たほうが早いです。**

なお、この40Lの現行モデル（VITC-40R）には**インナートレーが付属し、これを使うと深さは235mmになります。**
つまり**トレーを入れたままだと2Lは立ちません。**（[アイリスオーヤマのニュースリリース](https://www.irisohyama.co.jp/news/2026/?date=0225_2)）

**容量Lを増やしても、深さはあまり増えません。** 10Lと20Lで深さが同じ220mmという例もあります（ダイワ S1000X と S2000）。20Lは横に広がっただけで、深くはなっていません。

## 2Lペットボトルは何cmなのか

ペットボトルを製造しているメーカーの公表値です。

| 品名 | 断面 | 全高 |
|---|---|---|
| 1L角リブ | 85×85mm | **224mm** |
| 1L長角 | 80×70mm | 248mm |
| 1L平角 | 95×78mm | 250mm |
| 1L炭酸 | 82.3φ | 260.6mm |
| 1.5L平角 | 109×88mm | 285mm |
| 1.5L炭酸 | 92φ | **305mm** |
| **1.5L角** | 84.2mm | **307.5mm** ← 最も高い |
| 2L角ボトル(B) | 107×88mm | 305mm |
| 2L広口 | 106×88mm | 305mm |
| 2L角ボトル(A) | 108×89mm | **306mm** |

出典：[料材開発株式会社「飲料用ボトル 1L〜」](https://www.ryozai.com/buisiness/pet-original/water-bottle/detail-water1l)

## 1.5Lは2Lとほぼ同じ高さです

ここが一番の落とし穴です。

```
2L角ボトル(A) … 306mm
1.5L角        … 307.5mm  ← 2Lより高い
1.5L炭酸      … 305mm
```

**1.5Lのほうが高いものすらあります。**

「2Lは無理でも1.5Lなら入るだろう」という判断は成り立ちません。1.5Lは容量が減った分**細くなっているだけで、高さはほとんど変わらない**からです。

![大型ペットボトルの全高とクーラーボックスの深さを比べた図。1.5Lは305〜307.5mmで2Lの305〜306mmとほぼ同じ高さ、深さ255mm以下では両方立たない](/img/bottle-height-chart.svg)

例外は **1.5L平角（285mm）** です。これは横に平たい形なので背が低い。ただしそれでも、上の表で285mm以上の深さを持つ製品は40Lだけです。

## 1Lでも立たないことがあります

「1Lなら大丈夫だろう」も、必ずしも当てはまりません。

| ボトル | 全高 | 立てて入る製品 |
|---|---|---|
| 1L角リブ | 224mm | 15L・20L・25L・40L（深さ230mm以上） |
| 1L長角 | 248mm | 25L・40L |
| 1L平角 | 250mm | 25L・40L |
| **1L炭酸** | **260.6mm** | **40Lのみ** |

**1L炭酸ボトルは260.6mmあり、25Lクラス（深さ255mm）でも立ちません。**
炭酸飲料のボトルは圧力に耐えるために丸く細長い形をしていて、そのぶん背が高くなります。

そして**深さ220mmのモデル（ダイワ 10L・20L）は、1Lですら1本も立ちません。**

## 寝かせれば入る、とも限りません

立たないなら横にすればいい——ですが、それも入らない場合があります。

| 製品 | 内寸の最も長い辺 | 2L（306mm）を寝かせると |
|---|---|---|
| ダイワ S1000X（10L） | 260mm | **入らない** |
| アイリスオーヤマ HUGEL 15L | 302mm | **入らない**（4mm足りない） |
| ダイワ S1500（15L） | 360mm | 入る |
| ダイワ S2000（20L） | 390mm | 入る |
| ロゴス ハイパーL（20L） | 330mm | 入る |
| アイリスオーヤマ HUGEL 20L | 400mm | 入る |
| ダイワ S2500（25L） | 430mm | 入る |

**ダイワ10Lとアイリス15Lには、2Lは立てても寝かせても入りません。**
アイリス15Lは302mmで、306mmのボトルに**4mm足りない**という際どい差です。

なお寝かせると、ボトルの直径のぶん深さを使うだけで、上の空間が余ります。**同じ容量でも積める本数は落ちます。**

## 買う前に見るべき数字

```
2L・1.5L を立てたい        → 内寸の深さ 310mm 以上
1L（炭酸を含む）を立てたい → 内寸の深さ 265mm 以上
1L（角型のみ）を立てたい   → 内寸の深さ 230mm 以上
```

容量Lではなく、**内寸の「深さ」を見てください。**
カタログでは外寸しか書いていないこともあるので、その場合はメーカーの製品ページで内寸を探すことになります。

## この記事はこういう人向けではありません

- **500mlがメインの人** — 500mlは全高184.5〜230mmで事情が違います
- **保冷力で選びたい人** — ここでは寸法しか扱っていません
- **ソフトクーラーを探している人** — 内寸が公表されていないことが多く、この方法が使えません
