防災の備蓄でカセットボンベを買うとき、**何本買えばいいのかが分かりません。**

農林水産省は本数を出しています。岩谷産業は用途別の試算表を出しています。**ところがこの2つは、そのままでは突き合わせられません。**

農水省は「1人・1週間」で書き、岩谷産業は「2人分・1日3回・用途ごと」で書いているからです。**しかも岩谷産業の表には合計が書かれていません。**

そこで**足して、1人・1週間に直しました。**

> **答えだけ要るなら、農水省の目安どおり1人6本です。** 3本組なら1人2セット（[[LINK:イワタニ カセットガス 3本組]]）。理由は下で計算しています。

## 結論：6本に届くのは「10℃で全部の用途をまかなうとき」でした

| 使い方（2人分・1日3回） | 25℃ | 10℃ |
|---|---|---|
| 食事＋カップ麺＋飲み物＋お湯（**全部**） | 4.0本 | **5.8本** |
| 食事＋飲み物＋お湯 | 3.2本 | 4.5本 |
| 食事＋飲み物 | 2.4本 | 3.2本 |
| 食事だけ | 2.0本 | 2.5本 |

**1人・1週間あたりの本数です。当サイトの計算です。**

農水省の「約6本」に近いのは、**気温10℃で、食事もカップ麺も飲み物もお湯も全部カセットコンロでまかなう場合**でした。

⚠️ **だから「6本は多すぎる」という話ではありません。** 災害がいつ起きるか、何度の日かは選べません。**10℃より寒い日もあります。** 農水省の6本は、そこまで見込んだ数字だと読めます。

| 備えるもの | 期限の目安 | |
|---|---|---|
| カセットボンベ | 製造から約7年 | [[LINK:イワタニ カセットガス 3本組]] |
| カセットコンロ | 製造から約10年 | [[LINK:イワタニ カセットフー 達人スリムII]]／[[LINK:イワタニ カセットフー エコプレミアム3 CB-EPR-3]] |

⚠️ **ボンベはコンロの適合品を使ってください。** メーカーが指定していない組み合わせは使えません。

## 農林水産省は「1人／1週間で約6本」

[災害時に備えた食品ストックガイド](https://www.maff.go.jp/j/zyukyu/foodstock/chapter07.html)にこうあります。

> 1人／1週間当たり、カセットボンベ約6本の備蓄が必要となります

同じページに使用期限も書かれています。

> 注）使用期限にご注意（ボンベ：約7年、コンロ：約10年）

**ただし、6本が何をどれだけ使う想定なのかは書かれていません。**

## 岩谷産業は用途別の試算表を出しています

[ご存じですか？カセットボンベの備蓄目安](https://www.iwatani.co.jp/jpn/consumer/products/cg/useful/stockpile/)に、実験条件つきの表があります。**2人分・1日3回**の想定です。

| 用途 | 想定 | 水量 | 使用鍋 | 気温 | 時間 | 1日3回の消費 |
|---|---|---|---|---|---|---|
| 食事 | レトルト惣菜・パックご飯 各2個 | 1ℓ | 20cm両手鍋 | 25℃ | 強火4分30秒＋中火15分 | **141.6g** |
| | | | | 10℃ | 強火7分40秒＋中火15分 | **179.1g** |
| 食事 | カップ麺（大）2個 | 1.2ℓ | やかん | 25℃ | 強火5分 | **59.1g** |
| | | | | 10℃ | 強火8分 | **94.5g** |
| 飲み物 | 温かい飲み物 250cc×2杯 | 0.5ℓ | やかん | 25℃ | 強火2分30秒 | **29.4g** |
| | | | | 10℃ | 強火4分 | **47.1g** |
| お湯 | 洗浄・殺菌用 | 1.2ℓ | やかん | 25℃ | 強火5分 | **59.1g** |
| | | | | 10℃ | 強火8分 | **94.5g** |

同社はボンベの中身も書いています。

> イワタニカセットガス1本には250ｇ入っています

**ここまでは公表値です。合計は書かれていません。**

## 足すと、1日に何g使うのか

用途を組み合わせて足しました。**当サイトの計算です。**

| 使い方（2人分・1日3回） | 25℃ | 10℃ |
|---|---|---|
| 食事＋カップ麺＋飲み物＋お湯 | 289.2g | **415.2g** |
| 食事＋飲み物＋お湯 | 230.1g | 320.7g |
| 食事＋飲み物 | 171.0g | 226.2g |
| 食事だけ | 141.6g | 179.1g |

**ボンベ1本は250gなので、いちばん多い使い方だと10℃で1日1.66本です。**

## 1週間・1人あたりに直す

7日ぶんにして、2人分を1人あたりに割りました。

| 使い方 | 25℃ | 10℃ | 農水省の6本との差 |
|---|---|---|---|
| 食事＋カップ麺＋飲み物＋お湯 | 4.0本 | **5.8本** | **あと0.2本** |
| 食事＋飲み物＋お湯 | 3.2本 | 4.5本 | 1.5本少ない |
| 食事＋飲み物 | 2.4本 | 3.2本 | 2.8本少ない |
| 食事だけ | 2.0本 | 2.5本 | 3.5本少ない |

**10℃で全部まかなうと5.8本。農水省の約6本とほぼ一致しました。**

つまり「6本」は、**寒い時期にカセットコンロだけで生活する想定**だと読めます。電気やお湯が一部でも使えるなら、計算上はもっと少なくて足ります。

⚠️ **ただし備蓄は、足りなかったときに買い足せません。** 少ないほうに寄せる理由がありません。

## 気温が下がると1.26〜1.60倍になります

岩谷産業は理由も書いています。

> ガスの気化および沸き上がり時間は気温によって大きな影響を受けるため、必要な本数が変わります

25℃と10℃の消費量を割りました。**当サイトの計算です。**

| 用途 | 25℃ | 10℃ | 倍率 |
|---|---|---|---|
| 食事（強火＋中火） | 141.6g | 179.1g | **1.26倍** |
| カップ麺（強火のみ） | 59.1g | 94.5g | **1.60倍** |
| 飲み物（強火のみ） | 29.4g | 47.1g | **1.60倍** |
| お湯（強火のみ） | 59.1g | 94.5g | **1.60倍** |

**強火だけで使う用途は1.60倍、中火が混じる食事は1.26倍。** 中火の時間は気温で変わらないぶん、影響が薄まる形です。

⚠️ **10℃より低い気温の値は公表されていません。** さらに増えるはずですが、**この記事では計算していません。**

## 使用期限は、省庁とメーカーで一致しています

| | 期限の目安 |
|---|---|
| カセットボンベ | **製造から約7年** |
| カセットコンロ | **製造から約10年** |

農林水産省と岩谷産業が同じ数字を書いています。岩谷産業はこう説明しています。

> カセットこんろの部品には、ガス漏れを防ぐゴム部品が使用されており、ご利用の頻度に関わらず、経年劣化していきますので注意が必要です

> カセットボンベの製造年月日は、缶底の数字で確認しましょう

⚠️ 同社はこうも書いています。

> 缶底のアルファベットは製造年月日とは関係ありません。（Hは平成ではありません）

**7年で入れ替えが要るので、買い足しては使う「ローリングストック法」が推奨されています。**

## 備える前に決める3つ

```
① 何人分か        … 岩谷の試算は2人分。人数で割って掛け直す
② どの用途をまかなうか … 食事だけなら1人2.0〜2.5本、全部なら4.0〜5.8本
③ 何度を想定するか   … 25℃と10℃で1.26〜1.60倍違う
```

**迷うなら農水省の「1人6本」でよいと考えます。** 計算上いちばん多い使い方（10℃・全部）が5.8本で、それを上回る数字だからです。

⚠️ **7年で期限が来ます。** 4人家族なら24本。**まとめて買うと一斉に期限が来るので、少しずつ買い足すほうが管理しやすくなります。**

鍋の大きさで迷っている方は、[カセットコンロに9号土鍋は乗る？](/cassette-konro/donabe-nangou/)もどうぞ。
