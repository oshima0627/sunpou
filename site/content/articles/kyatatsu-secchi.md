脚立や踏み台は、**しまうときは薄い板**です。ところが**広げると床を取ります。**

売り場で見るのはたいてい広げた状態なので、しまうときの薄さは分かります。逆に、**通販でしまう寸法だけ見て買うと、広げたときに驚きます。**

メーカーは「設置寸法」と「収納寸法」を両方公表しています。**その比を計算しました。**

> 高さ・重さ・しまう場所をまとめて決めたい方は、[42製品の早見表をまとめた「脚立・踏み台の選び方」](/kyatatsu/erabikata/)をどうぞ。

## 奥行は、天板高さの0.6〜1.2倍でした

**設置奥行を天板高さで割ると、種類ごとに違う値になります。**

| 製品 | 天板高さ | 設置奥行 | 奥行 ÷ 天板高さ |
|---|---|---|---|
| 長谷川 SE-3a | 0.30m | 31cm | **1.03** |
| 長谷川 EFA-05 | 0.51m | 63cm | **1.24** |
| 長谷川 SWH-09 | 0.90m | 96cm | **1.07** |
| 長谷川 SE-8a | 0.79m | 66cm | 0.84 |
| アルインコ TBF-4 | 0.77m | 74cm | 0.96 |
| アルインコ TBF-8 | 1.61m | 131cm | 0.81 |
| 長谷川 RHB-09a | 0.81m | 60cm | 0.74 |
| 長谷川 RHB-21a | 1.99m | 124cm | **0.62** |
| アルインコ BSA-90A | 0.90m | 71.6cm | 0.80 |
| アルインコ BSA-270A | 2.70m | 181.7cm | 0.67 |

**踏台は高さと同じくらいの奥行が要り、はしご兼用脚立は高さの6〜8割で済みます。**

低くて安定させたいものほど、相対的に広く開く形です。⚠️ **理由はメーカーが説明していません。**

そして**同じシリーズなら、大きいサイズほど比率は下がります。** RHBは0.74から0.62へ、BSA-Aは0.80から0.67へ。

設置寸法の幅と収納寸法の幅を比べると、**多くのシリーズで同じ値です。**

| 長谷川 SE-8a | 47cm | 47cm |
| 長谷川 EFA-08 | 51cm | 51cm |
| 長谷川 RHB-18a | 62cm | 62cm |
| アルインコ CCA-80K | 47.9cm | 47.9cm |
| アルインコ TBF-4 | 43cm | 43cm |
| アルインコ BSA-180A | 73.2cm | 73.2cm |

**畳むときに動くのは奥行だけです。** 幅は買った時点で決まります。

## 買う前に測る3つ

```
① 設置奥行 … 広げたときに床が何cm要るか。しまうときの1.7〜14.5倍
② 設置幅   … 畳んでも変わらない。狭い場所ではこちらが先に効く
③ 収納奥行 … 9.6〜30cm。薄いものほど広げたときの差が大きい
```

**しまう場所と広げる場所は、別々に測ってください。** 薄くしまえることと、狭い場所で使えることは別の話です。

## この記事で扱っていないこと

- **作業に必要な余裕** — 昇り降りや体の向きを変えるぶんの余裕は入っていません。設置寸法そのものです
- **壁からの距離** — 壁際に置けるかは製品の形によります
- **収納時の全長** — 立ててしまうときの高さは[別の記事](/kyatatsu/omosa/)で扱っています
- **ピカ SEC-S・MCX の設置寸法** — 仕様表の列の並びが他社と違うため、この記事では扱っていません
- **樹脂製・木製の踏み台** — アルミ製だけを見ています
