運動会、帰省、釣り、まとめ買い。「20Lのクーラーボックスなら、500mlのペットボトルは何本入るんだろう」と調べて、答えが見つからずにここへたどり着いた方向けの記事です。

先に結論を書きます。

## 結論：容量Lでは本数は決まらない

同じ「20L」のクーラーボックスでも、メーカーが公表している本数はこれだけ違います。

| 製品（20L） | 公表されている500mlの本数 |
|---|---|
| ダイワ クールラインα3 S2000 | **18本** |
| ロゴス ハイパー氷点下クーラーL | **16本**（＋氷点下パック） |
| キャプテンスタッグ CS＋コールドクーラーボックス20 | **15本** |

**同じ20Lで15本と18本。3本違います。**

さらに、ダイワの1シリーズ内で「1本あたり何L必要か」を出すと、きれいに比例しません。

```
10L ÷  8本 = 1.25 L/本
15L ÷ 10本 = 1.50 L/本
20L ÷ 18本 = 1.11 L/本
25L ÷ 19本 = 1.32 L/本
```

つまり **「20Lなら○本」という換算式は存在しません。**
見るべきなのは容量Lではなく、**内寸の「辺の長さ」と「深さ」**です。

理由を順に説明します。

## そもそも500mlペットボトルは何cmなのか

ここが出発点です。**500mlペットボトルに決まった寸法はありません。**

ペットボトルを製造しているメーカーが寸法を公表しているので、そこから引きます。

| ボトルの型 | 胴径（断面） | 全高 |
|---|---|---|
| クリスタル角 | 59×59mm | 205mm |
| **ストレートスリム** | 59φ | **230mm** ← 最も高い |
| 角(A) | 63×63mm | 188mm |
| 角B／準耐熱角／耐熱角 | 60×60mm | 207mm |
| 角リブ | 62×62mm | 200mm |
| 菱形デザイン | 63φ | 205mm |
| 丸リブ | 66φ | 207mm |
| 炭酸 | 68.5φ | 198.6mm |
| 丸耐熱 | 68.5φ | 205.58mm |
| **丸** | **70.5φ** ← 最も太い | 184.5mm |

出典：[料材開発株式会社「飲料用ボトル 500ml〜」](https://www.ryozai.com/buisiness/pet-original/water-bottle/detail-water500)／[小林硝子株式会社「飲料500ml丸耐熱」](https://www.kgk-knet.co.jp/product/ms-05-0046/)

```
胴径  59mm 〜 70.5mm （1cm以上の差）
全高 184.5mm 〜 230mm （4.5cm以上の差）
```

**お茶や水によく使われる角型は細く、炭酸飲料の丸型は太い。**
この1cmの差が、あとで本数を2〜4割変えます。

## 内寸から本数を計算する

ペットボトルを立てて入れる場合、入る本数は**床に並べられる数**で決まります。

```
本数 ＝ (内寸の幅 ÷ 胴径 の整数部分) × (内寸の奥行 ÷ 胴径 の整数部分)

前提：内寸の深さ ≧ ボトルの全高
```

### この式が正しいか、メーカーの公表値で答え合わせします

ダイワは内寸と本数の両方を公表しているので、検算できます。

| 製品 | 内寸(cm) | 角型60mmで計算 | 丸型68.5mmで計算 | メーカー公表 |
|---|---|---|---|---|
| クールラインα3 S1000X（10L） | 17×26×22 | **8本** | 6本 | **8本** ✅ |
| クールラインα3 S1500（15L） | 17×36×23 | 12本 | **10本** | **10本** ✅ |
| クールラインα3 S2000（20L） | 22×39×22 | **18本** | 15本 | **18本** ✅ |
| クールラインα3 S2500（25L） | 22×43×25.5 | 21本 | 18本 | 19本（18〜21本の範囲内） |
| ロゴス ハイパー氷点下クーラーL（20L） | 33×26×24 | 20本 | 12本 | 16本（12〜20本の範囲内） |

**3製品は計算値とぴったり一致しました。** 残り2製品も、計算で出した下限と上限の内側に収まっています。

→ **この式で「◯〜◯本」のレンジは出せます。** ただし各メーカーがどの型のボトルを前提に数えたかは公表されていないので、**ひとつの数字に決め打ちはできません。**

## カタログの「○本」は、保冷剤を入れた実用値です

ロゴスの公表値がヒントになります。原文はこうです。

> ペットボトル500mlが16本と氷点下パックが入る容量です

角型で計算すると20本入るはずの箱に、**16本＋保冷剤**と書いてある。**差の4本分が、保冷剤の場所**ということです。

**カタログの本数は「箱に詰め込める幾何学的な上限」ではなく、「保冷剤を入れて実際に使える本数」。**
逆に言えば、保冷剤を入れないなら公表値より多く入る可能性があります。

## 深さ22cmが分水嶺。細長い銘柄は立ちません

もうひとつ、容量Lからは絶対に読めない落とし穴があります。

**ストレートスリム型のボトルは全高230mm。** 内寸の深さが22cm（220mm）のモデルには**立ちません。**

| 製品 | 内寸の深さ | 全高230mmのボトル |
|---|---|---|
| ダイワ S1000X（10L） | 220mm | **立たない** |
| ダイワ S2000（20L） | 220mm | **立たない** |
| ダイワ S2500（25L） | 255mm | 立つ |
| ロゴス ハイパーL（20L） | 240mm | 立つ |
| アイリスオーヤマ HUGEL 20L | 240mm | 立つ |
| アイリスオーヤマ HUGEL 15L | 243mm | 立つ |

立たないと横倒しにするしかなく、隙間が増えて本数はさらに落ちます。
**普段どの銘柄を買うかで、見るべき深さが変わります。**

## 床面積が同じでも本数は違います

ここが一番おもしろいところです。

ダイワ S2000 の内寸は 22×39cm、ロゴス ハイパーL は 33×26cm。
**床面積はどちらも858cm²、完全に同じ**です。それでも入る本数が違い、しかも**ボトルの型で優劣が入れ替わります。**

```
角型60mm     S2000 → 18本 ／ ロゴス → 20本   （ロゴスが多い）
丸型68.5mm   S2000 → 15本 ／ ロゴス → 12本   （S2000が多い）
```

理由は**割り切れ方**です。丸型68.5mmだと、S2000 は 22÷6.85＝3列・39÷6.85＝5列 で15本。ロゴスは 33÷6.85＝4列・26÷6.85＝3列 で12本。**端数として捨てられる幅が違う**だけで、3本の差が出ます。

→ **容量Lでも床面積でもなく、「辺の長さ ÷ 胴径」の端数が本数を決めています。**

同じ理由で、**丸型にすると本数が落ちる幅もモデルによって違います。**

```
ダイワ S2000        角型18本 → 丸型15本  （-17%）
ロゴス ハイパーL     角型20本 → 丸型12本  （-40%）
アイリス HUGEL 15L  角型15本 → 丸型 8本  （-47%）
```

お茶（角型）と炭酸（丸型）を混ぜて入れると、カタログの本数どおりには入りません。

## この記事はこういう人向けではありません

- **缶やパック飲料、食材がメインの人** — 缶の寸法は別なので、この計算はそのまま使えません
- **40Lを超える大型を探している人** — この記事は10〜25Lが中心です（40Lは早見表に参考として1点のみ）
- **保冷力だけで選びたい人** — ここでは寸法しか扱っていません
