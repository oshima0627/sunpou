# ベビーゲートを開口幅で選ぶ

ベビーゲートの通販ページでは「対応幅67〜91cm」「追加フレーム付き」が並びますが、**開口の実測幅だけでは足りません。**

メーカー公式の**本体・追加フレーム・ワイドパネルの公表取付幅**を突き合わせると、こうなります。

- **同じ「約70〜90cm対応」でも、メーカーごとにレンジの切り方が違います。** 追加フレーム0／1／2本の境界がズレます
- **開口100cmでは、カトージ本体レンジ（最大95cm）に入らず、日本育児はワイドパネルS側になります。** カタログの「対応幅」見出しだけでは書いていない判定です
- **階段上は公式が別物です。** カトージ LDK-STYLEⅡは階段上不可。日本育児のワイドパネルも階段上不可。階段上はねじ留め型（Ⅱプラス等）の公式案内を先に読む必要があります

開口幅×公表取付幅のマトリクスはこちらです → [ベビーゲートは開口に合う？本体＋追加フレーム／ワイドパネルの取付幅を計算](/baby-gate/opening-width-fit/)

数字はすべてメーカー公式ページの公表値と、そこからの当サイトの計算です。壁への実測適合や取付強度の実測ではありません。
