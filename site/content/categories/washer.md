# 洗濯機を防水パン・フタの高さ・ドアの前方スペースで選ぶ

ドラム式・縦型洗濯機の通販ページでは容量kgや乾燥方式が中心ですが、<strong>家の防水パンに置けるかは奥行内寸、上の棚に当たるかはフタ全開時の高さ、ドラム式のドアが前の壁や洗面台に当たるかはドア開け時の奥行で決まります。</strong>

<div class="topic-stack">
  <section class="topic">
    <span class="topic__label">防水パン</span>
    <h2 class="topic__title">ドラム式の条件は奥行内寸500〜540mm以上、外形奥行は633〜739mm</h2>
    <ul class="topic__points">
      <li><strong>4社8機種の条件は奥行内寸500〜540mm以上。</strong> パナソニック・日立・シャープは540、東芝は520と500</li>
      <li><strong>外形奥行は条件より110〜200mm長い。</strong> 壁から防水パン手前の内壁まではパナソニック590mm以上、東芝570mm以上</li>
      <li><strong>TOTOの洗濯機パンは、640・740の有効奥行580mmに対し、800・900は546mm。</strong> 540mm条件に対する余りは40mmと6mm</li>
    </ul>
    <a class="topic__cta" href="/washer/drum-waterproof-pan-fit/">防水パンの判定記事を読む</a>
  </section>
  <section class="topic">
    <span class="topic__label">縦型</span>
    <h2 class="topic__title">縦型の条件は奥行内寸507〜570mm以上、ドラム式より厳しい機種もある</h2>
    <ul class="topic__points">
      <li><strong>4社15機種の条件は奥行内寸507〜570mm以上。</strong> 日立は530、パナソニックは540、シャープは507〜550、東芝は510〜570</li>
      <li><strong>大きい機種ほど厳しいとは限らない。</strong> 外形奥行694mmのNA-FA12V6は540以上、外形奥行639mmのAW-10GM3は570以上</li>
      <li><strong>TOTOの800・900の有効奥行546mmには、550・570条件の3機種が届かない。</strong> 不足は4mmと24mm、640・740の580mmなら全機種が上回る</li>
    </ul>
    <a class="topic__cta" href="/washer/vertical-waterproof-pan-fit/">縦型の防水パン判定記事を読む</a>
  </section>
  <section class="topic">
    <span class="topic__label">上部クリアランス</span>
    <h2 class="topic__title">フタ全開時は1132〜1529mm、閉じた高さより242〜431mm高い</h2>
    <ul class="topic__points">
      <li><strong>4社15機種のフタ全開時は1132〜1529mm。</strong> いちばん高いのは東芝 AW-12DPB6 の1529、いちばん低いのはシャープ ES-GE5K の1132</li>
      <li><strong>閉じた高さとの差は242〜431mm。</strong> 東芝 AW-12DPB6・AW-10DPB6 が差431mmで最大</li>
      <li><strong>折れ時は全開より56〜195mm低い。</strong> 仕様表の高さだけでは吊戸棚との干渉は分からない</li>
    </ul>
    <a class="topic__cta" href="/washer/vertical-lid-open-height/">フタ開け時の高さの記事を読む</a>
  </section>
  <section class="topic">
    <span class="topic__label">前方スペース</span>
    <h2 class="topic__title">ドラム式のドア開け時の奥行は973〜1259mm、外形奥行より373〜520mm前に出る</h2>
    <ul class="topic__points">
      <li><strong>4社12機種のドア開け時の奥行は973〜1259mm。</strong> いちばん長いのはシャープ ES-X12C の1259、いちばん短いのはシャープ ES-7S2 の973</li>
      <li><strong>外形奥行との差は373〜520mm。</strong> 外形奥行600mmのシャープ2機種でも1110と973で違う</li>
      <li><strong>パナソニックは背面の壁面からLXシリーズ1236mm以上、SDシリーズ1137mm以上。</strong> ドア開け時の奥行1226・1127より10mm長い</li>
    </ul>
    <a class="topic__cta" href="/washer/drum-door-open-front-space/">ドアの前方スペースの記事を読む</a>
  </section>
  <section class="topic">
    <span class="topic__label">他社のパン</span>
    <h2 class="topic__title">同じ640でも内寸奥行は618mmと590mm。900は560mmと590mm</h2>
    <ul class="topic__points">
      <li><strong>640・740の内寸奥行は、LIXILが618mm、パナソニックが590mm。</strong> 差は28mm</li>
      <li><strong>800の内寸は両社とも744×584mm。</strong> 高さはLIXIL 82mm、パナソニック 55mm</li>
      <li><strong>LIXIL 900の内寸奥行560mmは、570mm以上の条件に10mm足りない。</strong> パナソニック900の内寸奥行は590mm</li>
    </ul>
    <a class="topic__cta" href="/washer/lixil-panasonic-pan-inner-depth/">他社パンの内寸記事を読む</a>

<p class="note-muted">数字はすべてメーカー公式の仕様ページ・カタログ・施工図・寸法図の公表値と、そこからの当サイトの計算です。実際の防水パン・吊戸棚・洗面所の前方スペースへの実測適合ではありません。TOTOの有効寸法はTOTOが参考値としている数字です。LIXILとパナソニックの内寸は各社が内寸として公表した呼びで、洗濯機側の奥行内寸と同じ測り方かは未検証です。</p>
