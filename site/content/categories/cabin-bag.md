# スーツケースを外寸で選ぶ

カタログや通販ページの「機内持ち込み対応」だけでは足りません。**航空機の機内持ち込みと新幹線の持ち込み、どちらもメーカー公表の外寸で判定します。**

メーカーが公表している**外寸（キャスター・ハンドル込み）と各社の各辺・3辺和ルール**を突き合わせると、航空機ではこうなります。

- **「機内持ち込み」でも Jetstar と 100席未満で落ちる製品が多いです**
- **今回照合した製品では、PROTECA スタリアCXR 02350 だけが全列○です**
- Ace パリセイド3-Z は ANA/JAL系の3辺和上限（115）ぴったりだが、Jetstar は幅で×

航空機向けの判定記事はこちらです → [機内持ち込みスーツケースは本当に持ち込める？メーカー外寸で一括判定](/cabin-bag/airline-fit-outer-dims/)

新幹線では、東海道・山陽・九州・西九州の特大荷物（3辺和160cm超〜250cm）ルールに同じ外寸を当てると、こうなります。

- **機内持ち込みサイズ5製品（拡張時含む）は、すべて和160以下で特大予約不要です**
- **航空機で落ちる外寸でも、新幹線の160までは余裕があることが多いです**

新幹線向けの判定記事はこちらです → [新幹線にスーツケースは持ち込める？メーカー外寸で特大荷物を判定](/cabin-bag/shinkansen-fit-outer-dims/)

容量（L）と泊数の関係は、6社の公表目安を並べると**同じ40Lが1〜2泊にも4泊にもなります** → [スーツケース40Lは何泊？](/cabin-bag/liter-nanpaku/)

数字はすべてメーカー・航空会社・JRの公式ページの公表値と、そこからの当サイトの計算です。実測ではありません。
