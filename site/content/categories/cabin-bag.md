# 機内持ち込みスーツケースを外寸で判定する

カタログや通販ページに「機内持ち込み対応」とあっても、**航空会社と機材（100席未満）で○×が分かれます。**

メーカーが公表している**外寸（キャスター・ハンドル込み）と、ANA・JAL・Peach・Jetstar・Skymark・AIRDOの各辺＋3辺和**を突き合わせると、こうなります。

- **「機内持ち込み」でも Jetstar と 100席未満で落ちる製品が多い**
- **今回照合した製品では、PROTECA スタリアCXR 02350 だけが全列○**
- Ace パリセイド3-Z は ANA/JAL系の3辺和上限（115）ぴったりだが、Jetstar は幅で×

最初の判定記事はこちらです → [機内持ち込みスーツケースは本当に持ち込める？メーカー外寸で一括判定](/cabin-bag/airline-fit-outer-dims/)

数字はすべてメーカー・航空会社の公式ページの公表値と、そこからの当サイトの計算です。空港ゲージの実測ではありません。
