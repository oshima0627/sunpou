# sunpou — 「寸法で選ぶ」

Amazon の商品比較サイト「**寸法で選ぶ**」のリサーチと原稿。

**現在の状況・判断待ち・次にやることは [HANDOFF.md](HANDOFF.md) を読むこと。**
このファイルにはプロジェクトの定義だけを置く（時系列のログは積まない）。

公開URL: **https://sunpou.nexeed-lab.com/**

## このリポジトリの目的

**カタログに書かれていない寸法**を、メーカー公表値から計算して答える比較記事を積み上げる。
報酬額の高さでは選ばない。

## ジャンル選定の条件

1. **メーカーをまたいで比べる必要がある、またはカタログに無い数値で決まる**
2. 型番が変わりにくく、1年後も同じ悩みで検索される
3. 検索して調べる人がいるのに、まともに比べた記事が少ない
4. 3,000〜15,000円（迷って調べる程度の金額）
5. 効果・効能を語る必要がない（薬機法・景表法の領域に入らない）

> ⚠️ **条件1は 2026-08-24 に書き換えた。** 元は「用途が決まっていて、選ぶ基準が数値やサイズで
> 比べられる」だったが、SERPを13キーワード調べた結果、**サイズ・型番のキーワードは
> 楽天/Amazon/価格.comが独占**し、**規格・等級の解説はメーカーと専門店が独占**していて、
> 個人が入る余地が無いと分かった。個人が勝てるのは
> **「1社では書けない横断比較」と「カタログに無い実測値・累計コスト」だけ。**
> 根拠は [docs/serp-check.md](docs/serp-check.md)。

条件5により、加湿器・電動歯ブラシ・枕・シャワーヘッド・電気毛布などは意図的に除外している。
数値比較自体は可能だが、「〜に効く」を避けると記事が痩せ、避けないと表現規制の領域に入るため。

## 記録のルール

- **検証済みの事実と、未検証の仮説を必ず区別して書く。** 未検証のものには `未検証` と明記する
- 検索ボリューム・競合記事の薄さは、キーワードツールと実際の SERP 目視で裏取りしてから
  「検証済み」に昇格させる。推測のまま断定しない
- 商品スペック（寸法・重量・規格）は必ず一次情報（メーカー公式・取扱説明書）で確認する。
  Amazon の商品ページの記載だけを根拠にしない
- ⚠️ **無料ツールの「0」を検証済みの事実として扱わない。**
  検索数ツールはロングテールのデータを持っておらず、需要があっても0と返す
  （[docs/serp-check.md](docs/serp-check.md)）
