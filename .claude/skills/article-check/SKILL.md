記事1本を `specs/article-contract.md` に照らして判定する。**直さない。判定して報告するだけ。**

## 前提

- 対象の記事パス（例 `site/content/articles/coolerbox-500ml-honsuu.md`）が分かっていること
- `specs/article-contract.md` と `specs/article-rubric.md` を**先に読むこと**

## 手順

### 1. ビルド（契約 A1）

```bash
npm run build --prefix site
```

終了コードが 0 でなければ**ここで止める。** 以降の検査は意味がない。エラーメッセージの
ファイル名と行を報告する。

### 2. 価格・在庫に触れていないか（契約 A2）

```bash
grep -n "価格\|在庫\|送料\|セール\|割引\|安い\|¥\|円" <記事パス>
```

⚠️ **`円` は `楕円` `円筒` `円形` で誤検出する。** ヒットを1件ずつ見て、価格の話かどうか判定する。
**Amazon規約なので、1件でもあれば不合格。**

### 3. リンク位置（契約 A3）

```bash
python tools/check-link-position.py
```

出力の末尾に「20% を超えています」の一覧が出る。**対象の記事がそこに入っていたら不合格。**

### 4. 図版が PowerPoint 版か（契約 A4）

```bash
grep -n "^eyecatch:\|](/img/" <記事パス>
grep -n "ORDER = \[" -A 40 tools/figures/figures.py
```

記事が参照する画像名が `ORDER` に無ければ不合格。**SVG を手書きしない**（`CLAUDE.md` の必須事項）。

### 5. 読んで判定する（契約 B1〜B3）

```bash
grep -n "実測" <記事パス>
grep -n "未検証\|未確認" <記事パス>
```

- **B1**：「実測」の各出現が、本当に測った値か。**計算値に使っていたら不合格**
- **B2**：一次情報で確認できなかった記述に印があるか
- **B3**：表の計算値を**1つ以上選んで自分で計算し直す**。合わなければ不合格。
  何を選んでどう計算したかを報告に書く

### 6. 一次情報の照合は `source-verifier` に投げる（契約 C1〜C3）

```
Agent(subagent_type="source-verifier", prompt="<記事パス> の引用文・数字・出典URLを照合してください")
```

⚠️ **`source-verifier` は `Bash` を持っていない。** ステップ1〜5をそこに投げない。役割を混ぜない。
⚠️ **書き手の「確認しました」を根拠にしない。** 必ず投げる。

### 7. 段階評価（`specs/article-rubric.md`）

契約が**全部通ったときだけ**採点する。落第の判定には使わない。

## 完了条件

- 契約の A1〜A4・B1〜B3・C1〜C3 すべてに合否が付いている
- **不合格の項目には「ファイル名:行番号」と該当箇所の引用がある**
- 1件でも不合格なら、結論は「公開不可」

## 失敗したとき

| 起きたこと | 対処 |
|---|---|
| ビルドが落ちる | エラーの行を直してから最初からやり直す。**落ちたまま先に進まない** |
| `check-link-position.py` が動かない | 先に `npm run build --prefix site` を実行する（`site/dist` を読むため） |
| `source-verifier` が「確認不能」を返す | **合格にしない。** ただし下の「403」を先に試す |
| 「HTTP 403 で取得できない」と返ってきた | ⚠️ **curl / WebFetch を弾くだけで、実ブラウザなら取れるサイトがある。** `mcp__claude-in-chrome__navigate` で開いて確かめる（2026-09-01 に `irisohyama.co.jp` で実際に取れた）。それでも取れなければ確認不能 |
| 出典URLが 404 だった | ⚠️ **値が正しくてもURLが違うことがある。** サイト内検索で正しいページを探す（アイリスオーヤマは15L/20L/40Lが**1ページにまとまっていた**） |
| 判定に迷う | **合格にしない。** 迷ったものは不合格側に倒し、迷った理由を書く |
