手順の原型は `docs/link-check-2026-08-31.md`。3つの層を分けて見る。

## 手順

### 1. 出力（本番HTMLの機械検査）

本番の `sitemap.xml` から全ページを取得し、`class="buy"` のリンクを数える。

```bash
curl -s https://sunpou.nexeed-lab.com/sitemap.xml | grep -o '<loc>[^<]*</loc>' | sed 's/<[^>]*>//g'
```

各ページを取得して確かめる項目：**本数／リンク先ホスト／`tag=` の値／`rel`／`k=` の欠落／
プレースホルダ（`link-todo`）の残り**。

⚠️ **`rel` は `nofollow sponsored noopener` でそろっていること。**

### 2. 計測（Amazon側でタグが効いているか）

`https://affiliate.amazon.co.jp/home` を開き、**クリック数が記録されているか**を見る。
記録されていれば、サイト → Amazon → レポートの経路が通っている。

⚠️ **クリック数を「外部の人が押した」と読まない。** 自分の確認と切り分けられない。

### 3. 着地（検索語がその商品を出すか）

```
https://www.amazon.co.jp/s?k=<検索語>
```

⚠️ **`tag=` を外した URL で測る。** タグ付きで開くと**自分の確認がアソシエイトのクリック数に積み上がる**。

判定：

| | 意味 |
|---|---|
| ◎ | 1位が目的の商品 |
| ○ | 2位以内 |
| △ | 3位以下、または親出品・セット買い・スポンサー枠が上位を占める |
| ✗ | **誤った商品に着地する** |

### 4. 検索語を変えるなら

⚠️ **一律のルールは使えない。商品ごとに測る。**
実例：長谷川・ピカは一般名詞を外すと1位になったが、**アルインコは悪化**した（2026-08-26）。
**達人スリムβ も短縮したら1位が別商品になった**（2026-08-31）。

**変更前と変更後の順位を両方測ってから適用する。** 良くならないなら触らない。

⚠️ **検索語を短くすると `aria-label` から商品名が消える**（`resolveLinks` は aria-label に検索語を使う）。
読み上げでの識別性が落ちるので、改善幅と釣り合うかを見る。

⚠️ **bash の出力に出た日本語をそのままクエリに使わない。** cp932 で化ける（2026-08-26 に実際に起きた）。
Python で URL エンコードしてから使う。

## 完了条件

- 出力の検査結果（本数・tag・rel・プレースホルダ）が数字で書かれている
- 測った検索語・着地順位・判定の表がある
- **変更したものは、変更前と変更後の順位が両方記録されている**

## 失敗したとき

| 起きたこと | 対処 |
|---|---|
| Amazon が CAPTCHA を出した | **解かない。** そこで止めて利用者に報告する |
| 検索語が0件 | 商品名をメーカー公式で確認する。**Amazonに取り扱いが無い可能性**（キャプテンスタッグで実例あり） |
| 短縮すると悪化した | **適用しない。** 測った結果をそのまま記録して残す |
