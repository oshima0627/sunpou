# 記事06：内寸の長辺で選ぶ大型クーラーボックス（ダイワ・シマノ 15製品）

作成日: 2026-08-24 ／ ステータス: **公開済み**（`/coolerbox/uchinori-nagasa/`）

## このテーマにした理由

### 需要（Googleサジェスト・実取得）

```
「クーラーボックス 内寸」
  → ★内寸60★ / ★内寸50cm★ / ★内寸80★ / ★内寸60cm★ / ★内寸40cm★ / ★内寸100★
「クーラーボックス 内寸6」
  → 内寸60 / 内寸60cm / 内寸65 / ★シマノ クーラーボックス 内寸60★
「クーラーボックス 60cm」
  → シマノ クーラーボックス 60cm / 釣り クーラーボックス 60cm
```

**サジェストが「内寸◯cm」という数値のバリエーションで埋まっている。** 大物釣りの需要。

### ⚠️ `serp-check.md` のルールとの緊張

`serp-check.md` は **「サイズ・型番系はECが独占して勝てない」** と判定している（✗型）。
**「内寸60cm」はまさにサイズ型なので、そのままでは危ない。**

`未検証` — DuckDuckGo（**Google ではない**）で「クーラーボックス 内寸60cm」を引いた結果：

```
1 monotaro / 2 askul / 3 amazon / 4 monotaro / 5 tsurihack /
6 tsuriikitai「大型クーラーボックスは釣りで何l？青物・ブリ用の内寸サイズ」/
7 kakaku / 8-10 monotaro・kakaku・amazon / 11 rakucamp / 12 prdse「容量・内寸」
```

→ **EC が上位を占めるが、釣り系メディアも入っている。**
→ **「内寸一覧」自体はすでに書かれている。空白地帯ではない。**

**だから記事の軸を「一覧」ではなく「メーカー横断で並べ替えたときに何が壊れるか」に置いた。**
具体的には**容量Lと長辺の順位が一致しない**という発見と、**斜め置きの対角線**（誰も計算していない）。

⚠️ **DuckDuckGo は Google ではない。** 順位の判定材料としては弱い。**Google での再確認は未実施。**

# 検証：計算結果

計算スクリプトは `scratchpad/big.py`。

## ★ 発見1：容量Lと長辺の順位が一致しない

| 比較 | 容量 | 内寸の長辺 |
|---|---|---|
| **ダイワ トランクマスターHD III 8000** | **80L** | **85cm** |
| **ダイワ トランクマスターHD II 6000** | **60L** | **85cm（同じ）** |

**20L大きくしても、まっすぐ入る長さは1mmも変わらない。** 増えるのは**深さ（23.5cm → 31.5cm）。**

ほかにも順位が逆転している組み合わせがある。

```
シマノ スペーザ350（35L）      59.2cm  ＞  ダイワ タフトランク4300（43L）  56.5cm
ダイワ クールラインα3 2500（25L） 43cm  ＞  ダイワ PV-REX 2800（28L）      42cm
ダイワ タフトランク4300（43L）  56.5cm  ＝  ダイワ ライトトランクα3200（32L） 56.5cm
```

**8L小さいほうが長い。3L大きいほうが短い。11L差で長さが同じ。**

## ★ 発見2：斜めに置くと4〜8cm、立体の対角なら8〜13cm伸びる

```
床の対角線   ＝ √(短辺² + 長辺²)
立体の対角線 ＝ √(短辺² + 長辺² + 深さ²)
```

⚠️ **これは幾何学的な最大長。** 実際に斜めに入れられるかは形状しだいで、**未検証。**

## 内寸÷外寸（記事04の指標を大型でも見る）
