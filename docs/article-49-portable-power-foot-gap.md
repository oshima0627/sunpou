## 3. 検算

`python3 tools/check-article-49.py`

最短辺 = min(3辺)。狭い = 最短 ≤ 190。広い = 最短 ≤ 320。荷室は長い辺 ≤ 荷室の短い辺（今回は全辺が630以下）。かごは大きい順に 515, 388, 355 以下。

| 判定 | 数 |
|---|---|
| 狭い足元に入る | 5 |
| 狭い足元から出る | 9 |
| 広い足元に入る | 14 |
| ヤリス・フィット・シエンタの荷室に入る | 14 |
| かごに3辺を割り当てて入る | 14 |

軸がある11機種は、最短辺が奥行。757の長い辺463mmとヤリス630mmの差は167mm。かごの515mmとの差は52mm。

## 4. 未検証・未掲載

- 足元の幅と高さ。シエンタ以外の足元。運転席の足元
- 約190mm・約320mmの「約」の幅。535の2mmが実物で残るか
- EcoFlow 3機種の、どの数が幅・奥行・高さか。DELTA 3の398mmを高さに読むと、かごの高さ388mmを10mm超える
- 横倒しを取説が禁じているか
- ヤリスでデッキボードが無いグレードの荷室高。シエンタE-Fourの荷室高。3列シート車の7名乗車時の荷室の箱
- 開口部、突起、ホイールハウスの出っ張り
- RIVER 3の3辺（ページに無かった）
- 販売終了のため母集団外: 521（522と同じサイズ）、767（長い辺525mmでかごより10mm長い）、F3800（最短辺388mm）、1000 Plus（最短辺260mm）、RIVER 2（最短辺145mm）
- Amazon商品ページ。型番と辺の一致を確認できなかった。直リンクは載せていない
