# アフィリエイトプログラムの前提調査

作成日: 2026-08-24

このリポジトリは「Amazon の商品比較記事」を作る前提で始まっているが、
**そもそも Amazon アソシエイトの料率・審査・規約を確認していなかった。**
ジャンル選定の前提が変わりうるので、先に一次情報で押さえた。

**検証ステータスの表記ルール**
- `検証済み` … Amazon 公式ページ（affiliate.amazon.co.jp）で本文を読んで確認したもの
- `未検証` … 個人ブログ・二次情報が出典、または自分で試していないもの

`検証済み`（リポジトリ全体を grep して確認）

| 探したもの | 結果 |
|---|---|
| 「Amazonアソシエイト」「アソシエイト」 | **ヒット0件** |

| 「アフィリエイト」 | ヒットするが**全て ASP 案件型ブログ**の文脈（A8.net） |

### リベにあるのは「ASP 案件型ブログ」の型

`libecity-library/docs/02c_fukugyo-jitsumu.md` の「ブログ・アフィリエイトで月5万円に届く順序」が該当。
出典はリベシティ ノウハウ図書館の会員記事（学長マガジンで紹介された記事）。要点：

```
❶ 売る商品を決める      ← ASP（A8.net など）で先に決める
❷ その商品を売るキーワードを選ぶ
❸ 上位を取れるタイトル・目次構成
❹ 執筆・公開
❺ 分析・改善
```

商品選定の最低基準（リベ側の記載）：**単価3,000円以上／承認率50%以上／使用経験があり心からおすすめできる**

### ⚠️ この型は、本リポジトリの方針とは前提が食い違う

リベの型は**報酬単価2,000〜3,000円の ASP 案件**を前提にしている。
一方、Amazon アソシエイトの料率は 2〜8%（後述）なので：

```
本リポジトリの想定価格帯 3,000〜15,000円
  × 家電・カメラ 2% →   60〜 300円/件
  × キッチン等   3% →   90〜 450円/件
  × スポーツ等   4% →  120〜 600円/件
```

**リベ基準（1件2,000円以上）を1桁下回る。**
「月1万円に必要な件数」で言えば、リベの型が5件で足りるところ、Amazon 単体では **20〜160件** 必要になる。

→ リベの型のうち**そのまま使えるのは ❷❸（キーワード選定・目次構成・お悩みキーワード戦略）だけ**で、
**❶商品選定の基準は Amazon には転用できない。** ここは別の設計が要る（未解決。「次にやること」参照）。

なお、リベ側にも転用できる形で残っている考え方：
- 「お悩みキーワード」＝商品名ではなく読者の悩みで引く（月間検索数10〜100を狙う）
- 「検索1ページ目に個人サイトがあるか」でキーワードの勝ち目を判定する
- 発信者チェックリスト「利害関係があるか／リスクを語るか／数字と出典があるか」
  → **アフィリエイト記事を書く側として、この3つを満たす記事にする**という基準に読み替えられる

## 2. 審査条件

`検証済み` 出典: [アソシエイト・セントラル ヘルプ](https://affiliate.amazon.co.jp/help/node/topic/G8TW5AE9XL2VX9VM)

| 項目 | 内容 |
|---|---|
| 販売実績 | **サインアップから180日以内に3件以上の適格販売** |
| 自己購入 | **審査対象にならない**（自分の注文はカウントされない） |
| サイト要件 | **オリジナル記事10件以上**、直近60日以内に更新があること、本人が所有・運営 |
| SNS の場合 | オーガニックフォロワー500以上、公開設定 |
| 期限切れ | 180日以内に達成できないとアカウントが無効になりうる |
| 却下理由 | タグ付きリンクの未使用、オリジナルコンテンツ不足、商標権侵害など |

→ **記事が10本揃ってからでないと申請しても意味がない。** さらに申請後180日で3件売る必要がある。
本リポジトリはまだ0本なので、**アカウント取得は「記事10本を書き上げた後」のタスク。**

## 3. 比較記事を書くうえで直接効く規約

`検証済み` 出典: [アソシエイト・プログラム・ポリシー](https://affiliate.amazon.co.jp/help/operating/policies/)

### ★ 最重要：価格を手打ちで書いてはいけない

比較記事は「価格の比較表」を作りたくなるが、規約上こうなっている：

- 価格を表示してよいのは **Amazon が提供するリンク経由、または API 経由で取得した場合のみ**
- 「新品」と「中古」の**最低価格を両方**表示すること
- 価格比較形式にする場合、**Amazon.co.jp の価格も併記が必須**
- **取得時点の日時**を併記すること（公式の例：`Amazon.co.jp 価格： ¥3,277 (2008年1月7日 14:11（日本標準時）時点 −詳細はこちら−)`）
- 「価格および在庫状況は表示された日付/時刻の時点のものであり…」という**免責文言**も必須

→ **「A社 4,980円 / B社 6,200円」と手で打った比較表は規約違反になりうる。**
比較軸は**価格ではなく、サイズ・重量・規格・耐荷重などの静的なスペック**に置く。
これは README のジャンル選定条件（「サイズ・規格・数値で決着がつく」）と方向が一致しているので、
**その方針を規約の側からも維持すべき理由がある**、ということになる。

### リンクの扱い

- 特別リンクは**自サイトから直接**アクセスさせる。リダイレクト経由・クローク・隠蔽は禁止
- ポップアップ／ポップアンダーでの表示は禁止
- Amazon 商標を検索広告のキーワードとして入札してはいけない
- 自分自身や関係者による購入は不可

### クッキー（成果が計上される期間）

- リンククリックから **24時間** でセッション終了
- ただし**24時間以内にカートに入れた商品は、そこから89日以内の注文まで有効**

→ ASP 案件の30日クッキーと比べて極端に短い。**「記事を読んだその場で買われないと報酬にならない」**前提で書く必要がある。
比較記事の結論を後半に置くと、離脱してから買われて報酬にならない。

### 開示文言の掲示が必須

`未検証`（公式ヘルプの存在は確認したが本文未読）
出典: [なぜ自分をアソシエイトとして識別する必要があるのですか？](https://affiliate.amazon.co.jp/help/node/topic/GHQNZAU6669EZS98)

サイトのトップページなど目立つ位置に、規約で定められた文言を掲示する必要がある。一般に使われている形：

```
Amazonのアソシエイトとして、[サイト名] は適格販売により収入を得ています。
```

→ **正確な文言は、アカウント取得時に運営規約の該当条項を直接読んで確定させること。** ここは孫引きしない。

### 印刷物・メール

- 印刷物、電子書籍、郵便、口頭での販促に Amazon 商標を使うのは禁止
- 例外的に、**求めに応じてなされた**メール・SMS・自身の SNS のダイレクトメッセージには特別リンクを含められる

## 4. PA-API（商品データを自動取得する API）

`検証済み` 出典: [PA-API を利用するための要件](https://affiliate.amazon.co.jp/help/node/topic/GVJ2BJP35457CLML)

- 利用にはアソシエイトの**有効なアカウント＋審査合格**が必要。申し込みだけでは使えない
- **売上実績が無いと利用開始できない**
- 取得したデータは**自サイト上での表示にのみ**使える。データマイニング・スクレイピング用途は禁止
- アクセスキー／シークレットキーの譲渡・開示は禁止

`未検証`（検索結果由来。公式本文での再確認が必要）
- **発送済み商品売上が過去30日以内に無いと、利用できなくなる恐れがある**
- 1日あたりの最大リクエスト数は 864,000（売上に応じて変動する方式）

→ **前項の「価格は API 経由なら表示できる」を実行するには PA-API が要る。だが PA-API は売上が立たないと使えない。**
つまり **立ち上げ期は価格を表示できない。** 最初の記事群は**価格に触れない構成**で書き切る必要がある。

## 5. 公式 vs もしもアフィリエイト経由

`未検証`（個人ブログ・ASP のヘルプページ由来。公式の料率表と1件ずつ突き合わせた確認まではしていない）

| | Amazonアソシエイト公式 | もしもアフィリエイト経由 |
|---|---|---|
| 審査 | 180日以内に3件の適格販売が必要 | **販売ノルマ不要。** 提携申請のみ（審査は1〜10日程度） |
| 料率 | 上表のとおり | **公式の90%**（例：8% → 7.2%、2% → 1.8%、0.5% → 0.45%） |
| W報酬制度（+12%） | — | **Amazon は対象外**（[もしも公式：W報酬制度](https://af.moshimo.com/af/www/about/reward)） |
| その他 | PA-API が使える | 「かんたんリンク」で Amazon・楽天・Yahoo! を1つのリンクに並べられる |

**要点：料率は公式のほうが常に高い。** もしもの利点は「審査ハードルの低さ」と「かんたんリンク」だけ。
「もしもは W報酬で12%上乗せされるから得」と書いている記事があるが、**Amazon は W報酬の対象外**なので誤り。

→ 判断：**記事10本を書いて公式に申請するのが本線。** もしもは、公式の審査に落ちた場合の回避策として持っておく。
ただし**楽天・Yahoo! を併記したい場合は、もしものかんたんリンクのほうが実装が楽**なので、そこは別途検討。

## 6. ステマ規制（景品表示法）

`未検証`（消費者庁の運用基準 PDF は未読。以下は解説記事由来）

- 2023年10月1日施行。「広告であることが分からない表示」が不当表示として規制対象になった
- アフィリエイト記事には **「PR」「広告」「アフィリエイト広告」** 等の表記を、
  一般消費者が分かりやすい位置に明記する必要がある
- 措置命令・課徴金の**対象は広告主（事業者）側**で、アフィリエイター側ではない
  → ただし ASP・広告主から掲載を止められるリスクはある
- 出典: [消費者庁「景品表示法とステルスマーケティング」PDF](https://www.caa.go.jp/policies/policy/representation/fair_labeling/assets/representation_cms216_200901_01.pdf)

→ Amazon の開示文言（第3節）とは**別物**。**両方要る。**
記事上部に PR 表記、サイト全体にアソシエイト開示文言。
