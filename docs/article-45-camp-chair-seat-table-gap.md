## 1. テーマの決め方

木曜分（アウトドア）。購入意図の高い型番別・条件別に寄せる。

候補のうち、既存と意図が重なるものは外した。

| 候補 | 扱い |
|---|---|
| ペットボトルが何本立つか | 既存のクーラーボックス記事（500ml・2L）と重なる |
| 鍋・五徳とコンロ | 既存のカセットコンロ・土鍋と重なる |
| テント床とマット枚数 | 記事43で公開済み |
| ポータブル電源の外形と車載 | 車の荷室を箱として公式カタログから揃える必要があり、今回は見送り |
| キャリーワゴンの折りたたみと積載 | 同上 |
| 焚き火台の内寸と薪の長さ | 薪の長さをメーカー一次で揃える確認が、今回の取得範囲では終わっていない |
| テント・寝袋・マットの収納サイズ | 3種の収納を足す問いは残る |
| チェア座面高とテーブル天板高 | **採用**。コールマン公式が差の式を書いていて、型番の段に当てられる |

本記事の問いは「天板高 − 座面高が、コールマン公式ショップの 25〜30cm（両端を含む）に入るか」。両端を含む根拠は、同じページの例（座面40cmならテーブル65cmと70cm）が差25cmと30cmであること。

## 3. 検算

`python3 tools/check-article-45.py`

差 = 天板 − 座面。25以上30以下が入る。

| 範囲 | 通り |
|---|---|
| 全体 | 135（15×9） |
| 帯に入る | 20 |
| 天板が座面より低い | 9 |
| 同じ高さ | 3 |
| 1〜24cm | 57 |
| 31cm以上 | 46 |
| コールマン同士（座面7×天板3） | 21通り中3通り。いずれも天板70cm |

天板70cm（バタフライと2FD）は各5通り。オサマリー64cmは5通り。バタフライ60cmとオサマリー56cmは各2通り。2FDの50cmは1通り。バタフライ41cm、オサマリー82cm、オサマリー38cmは0通り。

特徴文のロー40cmに置き換えても、15段では帯に入る段は増えない。焚き火18cmとの差は、41cmで23cm、40cmで22cm。

境界: スゴイッス・ロー32cmとオサマリー56cmは差24cm。スゴイッス・ハイ42cmとオサマリー64cmは差22cm。レイチェアMID 38cmと天板70cmは差32cm。

## 4. 未検証・未掲載

- 座ったときの膝の当たり、座面の沈み、地面の傾き
- 天板の下面までの空き。バタフライの特徴文に厚さ5.7cmとあるが、上面から引いたものが下面かは未検証
- 各社の「約」と測り方が同じか。スゴイッスはサイズ行だけ（約）で、座面高の行には約が無い
- バタフライのローが40cmか41cmか（ページ内で不一致。計算は仕様の41）
- オサマリーの38／56／64のどれがお座敷・ミドル・ハイか
- スゴイッスの全高 H69/86/90/94 と座面の段の対応
- ローチェア30に合うと書かれたワンアクションローテーブル竹の天板高（LV-091のページにcmが無い）
- スノーピーク公式ショップ（ec.snowpeak.co.jp）は取得日に 503。FDチェアのシート高460mmと、ワンアクションテーブルの地上高66cmは未掲載
- 座面40cmちょうどの型番は、今回のページに無い
- ハイバックの「テーブル70cm以上」は、座面がページ上で一意でないので未検証
- Amazon直リンクは載せていない
  - レイチェアNX18の商品ページ（ASIN B0DMJK4H73）は Model Number 2219647 と一致した。Product Dimensions は 50D×50W×106H cm で、公式の使用サイズ約62×91×106（h）cm（最大時）・座面幅約50cmと、幅と奥行が一致しない。直リンクにはしていない
  - スゴイッスの見つかったページ（ASIN B08K2GG9CS）は Model Number C1-774-TN で、サイズは W60×D70×H69/84.5/89/93.5cm。記事の C1-774-BK（W60×D66×H69/86/90/94cm）と色も寸法も違う
