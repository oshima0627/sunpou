## 差し替え先を「保冷剤」にした理由

記事01の検証で出た**未消化の発見**が、そのまま次の記事になる。

> ロゴス原文「500mlペットボトルが16本と氷点下パックが入る容量です」
> → **カタログの本数は幾何学的な上限ではなく、保冷剤を入れた実用値。**

つまり **保冷剤が何本分の場所を食うのかは、どのメーカーも書いていない。**
そして**保冷剤の寸法はメーカーが公表している。** 記事01と同じ「公表寸法から計算する」型で書ける。

### 需要の確認（記事01と同じ方法：Googleサジェスト）

`検証済み` — サジェストAPI（`/complete/search`, hl=ja, gl=jp）の実取得結果。

```
「クーラーボックス 保冷剤」
  → 入れ方 / 最強 / 蓋に固定 / 保冷剤なし / ★量★ / おすすめ /
    蓋につける / 入れない / 保冷剤付き
「クーラーボックス 保冷剤 何」
  → 何時間 / ★何個★ / 何度 / ★何個 入れる★ / 何時間もつ
```

**「入れ方」「量」「何個」がサジェストに出る。** ロングテールの需要はある（絶対値は不明）。

⚠️ **ただし検索意図の半分は保冷力（何時間もつか）。こちらは寸法では答えられない。**
→ **記事の冒頭で「場所の話しか扱わない」と明示する。** 保冷力はメーカーも公表していない。

### ★ 厚さが 25〜35mm の10mm幅に収まっている

```
厚さ  25 / 25 / 25 / 26 / 29 / 30 / 30 / 30 / 30 / 35 mm

```

**長辺は4倍違うのに、厚さはほぼ揃っている。** → **「厚さ25〜30mmが入る隙間があるか」だけで判定できる。**

# 検証：計算のしかた

計算スクリプトは `scratchpad/calc.py`（このリポジトリには含めない。数値は下に転記した）。

```
床の本数 ＝ ⌊W ÷ 胴径⌋ × ⌊D ÷ 胴径⌋            （記事01と同じ格子配置）
置き方は3通りで、それぞれ残る本数を計算する
  ① 床に寝かせる … 角に a×b を置く。残りのL字を2通りに分割して多いほうを採る。
                    厚さ + ボトル全高 ≦ 内寸の深さ なら、保冷剤の上にも立てられる
  ② 壁に立てかける … 床を食うのは厚さの分だけ。立てた辺 ≦ 内寸の深さ が条件
  ③ ボトルの上に載せる … 厚さ ≦（内寸の深さ − ボトル全高）が条件。床は食わない
```

## ★ 検証結果：減る本数は保冷剤の大きさでは決まらない

**クーラーボックス側の「余り」で決まる。余りは2種類ある。**

### 余りその1 — 深さの余り（＝ 内寸の深さ − ボトル全高）

| 製品 | 内寸の深さ | 角型207mmの余り | 厚さ25〜35mmの保冷剤が上に載る数 |
|---|---|---|---|
| ダイワ S1000X (10L) | 220 | **13mm** | **0/11** |
| ダイワ S1500 (15L) | 230 | **23mm** | **0/11** |
| ダイワ S2000 (20L) | 220 | **13mm** | **0/11** |
| ダイワ S2500 (25L) | 255 | 48mm | 11/11 |
| ロゴス ハイパー氷点下クーラーL (20L) | 240 | 33mm | 10/11（**XLの35mmだけ載らない**） |
| アイリス HUGEL 15L | 243 | 36mm | 11/11 |
| アイリス HUGEL 20L | 240 | 33mm | 10/11（同上） |
| アイリス HUGEL 40L | 310 | 103mm | 11/11 |

**ダイワの10L・15L・20Lは、500ml角型を立てると保冷剤を上に載せる余地が無い。**
今回の11製品の最薄が25mmで、余りが13mm・23mmしかないため。

⚠️ **ロゴスの20Lクーラーに、ロゴス自身の最大サイズ（氷点下パックXL・厚35mm）は上に載らない。**
（余り33mm）。丸型炭酸ボトル（198.6mm）なら余り41.4mmで載る。**ボトルの型で結論が変わる。**

### ★ 記事の核になる数字

**ダイワ S2000（20L・内寸22×39×深さ22cm）**、500ml角型は保冷剤なしで18本。

```
氷点下パックL（255×164×厚25）を床に寝かせる → 6本（-12本）
氷点下パックM（196×138×厚26）を壁に立てる  → 18本（±0本）
```

**同じ箱・同じ1枚で、6本と18本に分かれる。**
氷点下パックLは長辺255mmで、内寸の幅220mmを超えるため**立てられない。**
寝かせると残りの帯が56mm（60mm未満）になって**丸ごと死ぬ。**
