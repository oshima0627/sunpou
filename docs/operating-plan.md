## 1. 記事が示す手順（＝運営の骨格）

`検証済み`（2026-08-25 に本文を再読して確認）

```
STEP1 登録申請      → 申請した時点で商品リンクの作成・掲載が可能になる
STEP2 広告掲載      → 自分のメディアにリンクを貼る
STEP3 登録審査      → 申請から180日以内に3件の適格販売が発生すると審査が開始
STEP4 クリック＆購入 → 報酬発生
STEP5 報酬支払      → 最低支払額に達すると支払い
```

記事の原文で、運営に直接効く記述：

| 記述 | 効き方 |
|---|---|
| 「登録後180日以内に3件の成果が必要（購入されること）！これをクリアできたら、正式に本審査」 | **3件が先、本審査が後** |
| 「ブログやSNSなど全て同一のアソシエイトアカウントのリンクを貼るので**ブログで2個、Xで1個などで完了**」 | **媒体をまたいで合算される** |
| 「クリックさえしてもらえたら勝ち」＝**紹介した商品以外が買われても報酬になる** | ついで買いを拾える（これは公式とも一致） |
| 登録方法：公式ページ → 無料アカウント作成 → **サイト/SNSのURL登録** → **支払い情報・税務情報** → 審査待ち | 手続きの実体 |

## 5. ★ 最大の論点：180日で3件をどう作るか

`検証済み`（公式・記事とも一致）— **自己購入はカウントされない。家族に依頼するのもNG。**
→ **他人に買ってもらうしかない。**

`検証済み`（`serp-check.md`）— **SEOで順位が付くまで数週間〜数ヶ月。**

```
2026-08-25 に申請 → 期限は 2027-02 中旬ごろ
```

**申請のタイミングは、早い/遅いで利害が逆になる。**

| | 早く申請 | 遅く申請 |
|---|---|---|
| 良い点 | リンクを早く貼れる＝**測定が早く始まる** | 180日を**記事が揃った状態で使い切れる** |
| 悪い点 | 記事が10本無い状態で本審査に入るリスク | 測定の開始が遅れる |

### わたしの推奨：**記事を10本にしてから申請する**

理由は3つ。

1. **公式のサイト要件が「オリジナル記事10件以上」なので、確実に満たしてから180日を使いたい**
2. **10本にするのはわたしの作業で、待ち時間は短い**（利用者を待たせない）
3. 記事の言う「フォロワーが少なくても問題なし」は**著者自身が「のはず」と書いた推測**で、寄りかかれない

→ **記事10本＋収益記事＋リンク実装の準備が終わった時点で「申請してください」と合図します。**
