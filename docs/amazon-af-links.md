# Amazonアソシエイト広告バナー（links.json）

作成日: 2026-09-18

## なにをする仕組みか

`site/content/links.json` は広告リンクの台帳です。記事本文の `[[AF:キー]]` / `[[AFSide:キー]]`、およびカテゴリ既定の H2 間自動挿入・サイドバー静音バナーが、ここを引きます。

- **URL は Associates 形式のみ**（`https://www.amazon.co.jp/s?k=…&tag=sunpou-22` など）。推測で組み立てた ASP URL や、kakei のもしも `a_id` は入れない。
- **商品画像・Creators API は使わない**（適格販売 10 件 / 30 日が必要なため）。表示は CSS のコンパクトバナー（タイトル＋短いラベル＋↗）。
- 既存の `[[LINK:検索語]]`（表セル・製品カード）はそのまま。バナーはカテゴリ横断の「探す」導線。

## マーカー

| 書き方 | 効果 |
|---|---|
| `[[AF:キー]]` | プールに入り、H2 間に回転挿入（本文末のマーカーは剥がす） |
| `[[AFSide:キー]]` | 右サイドバーへ静音バナー（本文には出さない） |
| （マーカーなし） | `affiliateEnabled` 時、記事の `category` に紐づくキーを自動プール／サイド1本 |

## もしもアフィリエイトについて

**sunpou では対象外。** kakei（メディア ID 687816 等）の案件・バナー HTML を流用しない。sunpou 用のもしもメディアができてから別途検討する。

## 開示

- 記事冒頭の PR 表記（`prLabel`）とフッターの Amazon 開示（`affiliateDisclosure`）は従来どおり。
- サイドバーのバナーに「広告」バッジは付けない（静音）。本文バナーも長文 CTA は付けない。
