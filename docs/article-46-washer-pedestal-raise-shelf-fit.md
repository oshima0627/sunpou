## 1. テーマの決め方

月曜分（洗濯機・冷蔵庫）から1本。2026-10-28 承認の改善案は、購入意図の高い型番別・条件別に寄せる。記事44の次回候補3が「かさ上げ台を足したときの投入口高さ」、候補4が「縦型の閉じた全高を棚下の上限で分ける」。

候補のうち、既存と意図が重なるものは外した。

| 候補 | 扱い |
|---|---|
| 棚下に置ける縦型（閉じた全高だけ） | 公式のかさ上げを足す本記事に含めた。フタ全開の記事とは別の問い |
| 640パン対応ドラムの一覧 | 既存 `/washer/drum-waterproof-pan-fit/` と `/washer/lixil-panasonic-pan-inner-depth/` |
| 冷蔵庫の放熱スペース | 既存の据付奥行・左右上方あきと重なる |
| 型番別の置ける／置けない（置き場の上限） | 記事41が幅×奥行、記事42が洗濯機の外形奥行 |
| かさ上げ台使用時の高さ | **採用**。公式が「何mm高くなる」と書いた部品だけを、閉じた全高に足す |

本記事の問いは「公式のかさ上げを足した閉じた全高が、棚下1100／1200／1300mmに入るか」。投入口の絶対値、フタ全開、ドアの前方、防水パンの内寸は判定に入れず、各記事へリンクした。

クーラーボックスは増やしていない。新カテゴリは作っていない。

## 4. 未検証・未掲載

- 実住宅の床から棚下まで
- 約の端数
- TW-AS3 を2枚重ねた合計mm
- TW-84・TW-127 の据付説明書が部品を名指ししているか
