# 記事01：クーラーボックスに500mlペットボトルは何本入るか

作成日: 2026-08-24 ／ ステータス: **データ収集中（原稿未着手）**

## この記事を最初に選んだ理由

`docs/serp-check.md` の判定を踏まえた運用判断。3候補（おむつ用ゴミ箱／ラベルライター／クーラーボックス）から
クーラーボックスを選んだ。決め手は**規約制約**。

| | 差別化点 | 価格を使うか |
|---|---|---|
| おむつ用ゴミ箱 | カートリッジの**ランニングコスト** | **使う** → 規約に抵触 |
| ラベルライター | テープの**累計コスト** | **使う** → 規約に抵触 |
| **クーラーボックス** | **500mlが何本入るか** | **使わない**（寸法だけで決まる） |

`affiliate-program-facts.md` 第3節のとおり、**価格は手打ちで書けない**（リンク／API経由のみ・
日時と免責の併記が必須）。しかも PA-API は売上が立つまで使えないので、**立ち上げ期は価格に触れられない。**
→ **ランニングコスト系の記事は、いま書くと片手を縛られる。** 寸法だけで完結するテーマを先に書く。

### 勝てる根拠（`serp-check.md` より）

- **知恵袋が1位**＝まともな比較記事が無い
- **サジェストが本数バリエーションで埋まっている**（500ml 4本／6本／8本／10本／12本／20本／24本／
  ペットボトル 縦／6本 何リットル）＝需要が構造的
- **「カタログに無い実測値」型**＝メーカーも専門店も横断で書けない領域

## ★ 当初の懸念が外れた：実物を測らなくても書ける

着手前の想定は「実測しないと書けない（＝AI側では無理）」だったが、調べたら違った。

**メーカー自身が「500mlが何本入るか」を公表している場合がある。**
公表していないメーカーは、**公表されている内寸から計算できる。**

## ★ 記事の核になる発見

### ① 同じ「20L」でも本数が違う。容量Lでは決まらない

```
DAIWA 2000（20L）  → 18本
LOGOS ハイパーL（20L）→ 16本（＋氷点下パック）
```

さらに DAIWA 内で1本あたりの容量を出すと**非線形**：

```
10L / 8本  = 1.25 L/本
20L / 18本 = 1.11 L/本
25L / 19本 = 1.32 L/本
```

→ **「20Lなら○本」という換算は成立しない。** これが読者の困りごとの正体。

### ② 決めているのは「内寸の床面積」

500mlペットボトルを**縦置き**する場合、入る本数は床面に並べられる数で決まる。

```
本数 ＝ floor(内寸の幅 ÷ ボトル直径) × floor(内寸の奥行 ÷ ボトル直径)
前提：内寸の深さ ≧ ボトルの高さ
```

### ③ この計算方法は、DAIWA の公表値と完全に一致した

500mlペットボトルを **直径 約6.5cm × 高さ 約21cm** として計算：

| 製品 | 内寸 | 計算 | 計算結果 | 公表値 | 判定 |
|---|---|---|---|---|---|
| DAIWA 1000X | 17×26×22 | ⌊17/6.5⌋=2 × ⌊26/6.5⌋=4 | **8本** | **8本** | ✅ **一致** |
| LOGOS ハイパーL | 33×26×24 | ⌊33/6.5⌋=5 × ⌊26/6.5⌋=4 | 20本 | 16本＋パック | ⭕ **差の4本分は氷点下パック**（メーカー自身がそう書いている）で説明できる |
| アイリス HUGEL 20L | 40.0×21.5×24.0 | ⌊40/6.5⌋=6 × ⌊21.5/6.5⌋=3 | **18本** | 公表なし | — |
| アイリス HUGEL 15L | 30.2×18.2×24.3 | ⌊30.2/6.5⌋=4 × ⌊18.2/6.5⌋=2 | **8本** | 公表なし | — |

→ **DAIWA の公表値を再現できた**ので、この計算は使える見込みが立った。
さらに **LOGOS の「16本」はパック込みの数字**だと分かる。
つまり **カタログの本数は「保冷剤を入れた実用値」で、幾何学的な上限ではない。** ここは記事にできる。

### ④ 深さで「縦置きできるか」が決まる

上表はすべて深さ22cm以上で縦置きできた。**深さ21cm未満のモデルは縦置き不可**になり、
横置き（＝デッドスペースが増える）になる。**選ぶときに見るべきは容量Lではなく内寸の深さ。**

## ⚠️ 未検証（記事化の前に必ず潰す）

| # | 項目 | なぜ問題か |
|---|---|---|
| **1** | **500mlペットボトルの直径6.5cm・高さ21cm という前提** | **記事の全数値がこの1点に乗っている。** 一次情報で確認していない（一般知識で置いた値）。DAIWA の公表値を再現できたのは強い裏付けだが、証明ではない |
| 2 | 500mlボトルは**銘柄で寸法が違う**（丸型／角型、直径5.5〜7cm） | 直径7cmなら列数が減り本数が変わる。**むしろこれ自体が記事の内容になる**（「どの銘柄で数えたか」を明示する） |
| 3 | DAIWA 1500/2000/2500 の内寸 | 未取得。取れば検証サンプルが3つ増える |
| 4 | 対象モデルが**釣り・アウトドア系に偏っている** | README の価格帯（3,000〜15,000円）に対し、DAIWA クールラインα3 は希望本体価格 15,400〜40,400円で**上振れしている**。価格帯に合うモデルを別途拾う必要がある |
| 5 | 内寸の測り方がメーカー間で統一されているか | 同じ「内寸」でも突起部を含む／含まないの差がありうる |

## 記事構成案

```
H2 結論：容量Lでは本数は決まらない。見るのは内寸
   └ 同じ20Lで16本と18本の実例を先に出す（読者の前提を壊す）
H2 500mlペットボトルは直径何cm・高さ何cmか
   └ どの銘柄で測ったかを明示。丸型と角型の差にも触れる
H2 内寸から本数を出す計算
   └ 式 → DAIWA の公表値と一致することを見せる（＝この記事の信頼性の担保）
H2 カタログの「○本」は保冷剤込みの実用値
   └ LOGOS の「16本＋氷点下パック」を根拠に
H2 縦置きできるかは「深さ」で決まる
   └ 深さ21cm が分水嶺
H2 容量別の早見表
   └ 内寸・計算本数・公表本数を並べた表。出典URLを全部付ける
H2 こういう人はこの記事の対象ではない
   └ 缶・食材メインの人／大型（40L超）を探している人
```

⚠️ **価格・在庫には一切触れない構成にする**（規約制約。`affiliate-program-facts.md` 第3節）。
比較軸は内寸・深さ・本数・重量のみ。
