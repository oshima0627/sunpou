## ★ 訂正した記述（公開済みの2記事）

### 記事18「火力が強い機種ほど、早く終わります」は成り立っていなかった

公開時の本文：
> 消費量の順に並べると、そのまま燃焼時間の逆順になります。
> **火力が強い機種は、鍋が小さく、燃焼時間も短い。** 3つとも同じ向きに動きます。

**11機種で検定すると成り立たない。**

| | 順位相関（spearman） |
|---|---|
| 最大発熱量 vs ガス消費量 | **+0.998**（ほぼ完全に連動） |
| 最大発熱量 vs 連続燃焼時間 | **−0.332** |
| 同（ミニを除く10機種） | **−0.096**（ほぼ無相関） |
| ガス消費量 vs 連続燃焼時間 | −0.331 |

**「火力が上なのに燃焼時間も長い」組み合わせが16組**あった。いちばん明快な反例：

```
スマート        3.5kW ／ 254g/h → 78分（11機種で最長）
エコプレミアムIII 2.9kW ／ 210g/h → 72分
```

⚠️ **記事18が持っていた9機種のデータでも、すでに成り立っていなかった。**
9機種だけで測っても spearman **−0.391** で、消費量順に並べると
**ウィンドシールド78分 → 達人スリムV68分**で順序が崩れる。
**新しいデータで結論が変わったのではなく、最初から誤りだった。**
記事18はBOとエコプレミアムIIIの2機種だけを見て一般化していた。

**理由は記事18の主題そのもの。** 燃焼時間は「250g ÷ 消費量」からの上振れで決まり、
その上振れが **+1分〜+19分**とばらつくため、消費量の順位からは決まらない。

→ 記事18の該当節を「**火力の強さでは、燃焼時間は決まりません**」に書き直し、
訂正した旨を本文に明記した。表も11機種に増やした。
