## 構造（クーラーボックスの収益記事と同じ）

1. **30秒で決めるなら** — 用途 → 必要な足場の高さ → 候補（リンク付き）
2. 「足を置ける高さ」は種類ごとに違う欄を見る、の説明
3. **42製品の早見表**（踏台6／上わく付き踏台11／脚立25）
4. 使用最大高さ非公表の5シリーズ（別表）
5. しまう場所から選ぶ
6. 重さから選ぶ
7. 買う前に測る数字
8. 扱っていないこと／出どころ

**リンク60箇所。最初のリンクは本文の8.2%の位置**（クッキー24時間対策の20%以内）。

## 逆引きの式

```
必要な足場の高さ ＝ 届きたい高さ − 身長
```

長谷川工業のサイズ目安表「身長＋踏台の天板高さが、作業高さとなります」を逆に使った。
同社は身長160cm基準と明記している。**この式を使う根拠は記事13でも整理済み。**

⚠️ **天井2.1m は建築基準法施行令 第21条の下限。**
「居室の天井の高さは、二・一メートル以上でなければならない」（e-Gov で本文確認済み）。
**実際の天井高は測ってもらう前提**と記事に明記した。

## 早見表に入れなかったもの

| 除外したもの | 理由 |
|---|---|
| アルインコ BSA-A（7サイズ） | 使用最大高さ非公表 → 別表に天板高さだけ載せた |
| ピカ SEC-S・MCX・SXJ・SCL | 同上 |
| 長谷川 RYZB-21a | **使用最大高さが18aと同一で行ずれの疑い**（`docs/article-12-kaidan.md`） |
| 長谷川 RYZB-24a | 質量が取れていない |
| 長谷川 SWH-15 | 質量が取れていない |
| 長谷川 SRA の質量 | 仕様表が「-」→ 高さと寸法だけ載せて質量は「—」 |
| 長谷川 RYZB-15a の収納高さ | **仕様表が「1140」cm。140の桁ミスとみられるが公表値のまま扱わず空欄** |

**除外したことは記事本文にも書いた。**

## 未検証（昇格させないこと）

- **実際の住宅の天井高の分布。** 法令の下限2.1mしか根拠がない
- **手が届く高さの個人差。** 長谷川の式をそのまま使っている
- **使用最大高さ非公表シリーズの実際の値。** 「他社が天板−30cmなので同じくらいと考えるのが安全」とだけ書いた
- **SERPの勝ち目。** 「脚立 選び方」「踏み台 選び方」の順位は見ていない
