# 記事40 縦型洗濯機の投入口の高さ（`/washer/vertical-opening-height/`）

公開 2026-10-25。カテゴリ `washer`（洗濯機）の6本目。docs 番号は `article-39-*` が最後のため、次の空き **40** を採用（34 は欠番のまま）。

データ取得日はすべて **2026-10-25**。数値は保存した公式HTMLを文字列検索して確認した。寸法図の画像だけにしか無いmmは記事に書いていない。

## 1. テーマの決め方

- 第一候補は縦型の投入口（開口部）の高さ・口径・本体高さ。既存の `/washer/vertical-lid-open-height/` はフタ全開時の上方、`/washer/vertical-waterproof-pan-fit/` は防水パンの奥行内寸で、開口の縁とは別
- 記事37・38・39の次候補に残っていた「縦型の投入口高さ」を採用
- 円の「口径」は4社とも公表していない。パナソニックと東芝は幅×奥行
- 勝てる型：①メーカー横断（東芝／シャープ／日立／パナソニック。呼びは揃えない）②カタログ欠落計算（総外形−手前、ホース込−投入口、12kgと10kgの差）
- 切り口：**仕様の高さは給水ホースを含む本体の高さ。東芝の手前は826〜891mmで、12kgより10kgが65mm低い。総外形との差は12kgも10kgも207mm**

外形高さは `/wash/common/json/bw-*.json` の「高さ」。X100M・X90M・V100M は 1,000mm、V80M は 930mm。注記は給水ホース取付部・排水ホースを含む。
