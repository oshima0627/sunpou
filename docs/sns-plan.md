## 2. SNS を登録するときの必須条件（公式）

`検証済み` — 上記2ページの本文より。

- **アソシエイトリンクを使うURLは、漏れなく全て登録する。**
  「登録が無いURLでの使用が確認された場合…**契約解除の対象**となる場合がございます」
- **公開状態でなければならない**（非公開SNSでの参加は不可）
- **フォロワー数／登録者数が見えるページであること**
- **オーガニックフォロワーが一定数必要。ほとんどの場合、最低ラインは 500**
- URLは個人ページまで正確に（`https://twitter.com` だけでは不可）
- **トラッキングIDはサイトごとに分けられる** → SNS経由とサイト経由を分けて測れる

## 3. ★ 設計上の結論：**SNSにアフィリエイトリンクを貼らない**

**SNSには自サイトの記事へのリンクだけを貼り、商品リンクは記事の中で踏んでもらう。**

理由は3つ。

| # | 理由 |
|---|---|
| 1 | **500フォロワーの壁を回避できる。** アフィリエイトリンクを貼らなければ、そのSNSは「アソシエイトリンクを使うURL」ではないので登録義務も条件も掛からない |
| 2 | **未登録URL問題（契約解除リスク）を根本から避けられる** |
| 3 | **記事にはすでに139本のリンクがある。** 記事に来てもらえれば導線は完成している。しかも**滞在中に読者が納得してから**リンクを踏むので、SNSから直リンクするより筋がいい |

⚠️ 当初「媒体をまたいで3件を合算する」ことを狙っていたが、**自サイト経由でも3件はカウントされる**ので、この設計でも目的は達成できる。

⚠️ **将来フォロワーが500を超えて、SNSに直リンクを貼りたくなった時点で登録すればよい。**
そのときは**必ず先に登録してから貼る。**

## 4. どのSNSが相性がいいか

### このサイトのコンテンツの性質

```
・数字と表と図（SVGの図版が10本ぶんある）
・「へえ」と思わせる発見型（80Lと60Lは内寸の長辺が同じ85cm、など）
・検索意図型（2Lは立つ？ 保冷剤は何枚入る？）
・季節性がある（クーラーボックス＝夏／カセットコンロ＝冬）
```

### 評価

| SNS | リンク | 数字・図との相性 | 日本での規模 | 制作コスト | 判定 |
|---|---|---|---|---|---|
| **X（旧Twitter）** | **本文に貼れる** | **高**（画像＋短文＋リンクが素直に出せる） | **大** | **低** | **◎ 本命** |
| **Pinterest** | 貼れる | **最高**（図解がそのまま資産になる・検索型で長寿命） | 中（`未検証`） | 低（**既存SVGを画像化して流用できる**） | **○ 併用候補** |
| Instagram | **フィード投稿に貼れない**（プロフィール／ストーリーズのみ） | 高 | 大 | 中 | △ 導線が弱い |
| YouTube | 貼れる | 中 | 大 | **高**（動画制作） | ✗ コストが見合わない |
| TikTok | 制約あり | 中 | 大 | **高** | ✗ 同上＋公式ヘルプの列挙に無い |
| Threads / Bluesky | 貼れる | 中 | 小 | 低 | △ 規模が小さい |

### 本命は X

- **リンクが本文に貼れる**のが決定的。Instagram はここで脱落する
- **数字ネタと相性がいい。** 「80Lと60Lは、まっすぐ入る長さが同じ85cmでした」は、そのまま1投稿になる
- **図版がすでに10本ある。** SVGをPNGにすれば画像付き投稿がすぐ作れる
- コストが低く、**記事を書くついでに出せる**

### 併用するなら Pinterest

- **図解の資産性が高い。** Xの投稿は数時間で流れるが、Pinterestのピンは**検索経由で何ヶ月も拾われる**
- **季節先取りに強い。** いまは8月末で**クーラーボックスの需要は終わりかけ、カセットコンロはこれから**。
  冬向けの土鍋ネタを今から積むのに向く
- ⚠️ **ただし Amazon 公式ヘルプの片方に Pinterest が列挙されていない。**
  → **第3節の設計（アフィリエイトリンクを貼らず記事に送る）なら、この問題は発生しない**

`未検証` — 日本国内の Pinterest 利用者数と、このジャンルでの実際の流入。**やってみないと分からない。**

## 5. 推奨する進め方

1. **まず X を1つ作る。** アカウント名はサイトと揃える（例：`@sunpou_lab`）
2. **プロフィールに記事URLを置く**（`https://sunpou.nexeed-lab.com/`）
3. **投稿は「数字＋図版＋記事リンク」の形。** アフィリエイトリンクは貼らない
4. **反応が出たら Pinterest を足す。** 既存のSVGを画像化して流用する
5. **フォロワーが500を超えて直リンクを貼りたくなったら、先にアソシエイトにURLを登録する**

### 測定

**SNS用に別のトラッキングIDを作る必要はない**（SNSに直リンクを貼らないため）。
分けて見るのは Cloudflare Web Analytics の**参照元**で足りる。
