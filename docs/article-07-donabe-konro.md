# 検証：計算結果

## ★ 発見1：「10号まで」の機種の本体幅より、10号土鍋のほうが大きい

```
エコプレミアムIII（10号まで） 本体幅 33.4cm
花三島 10号                 幅 34.0cm  → 0.6cm はみ出す
墨貫入 10号                 幅 36.0cm  → 2.6cm はみ出す
```

⚠️ **「はみ出す＝使えない」ではない。** メーカーが言っているのは五徳に乗るかどうかで、
鍋がコンロ本体より大きいこと自体は普通に起こる。**記事でもそう書いた。**

**実務的な意味は「卓上で必要な場所は、コンロの外寸ではなく鍋の幅で決まる」ということ。**

## ★ 発見2：9号でも、機種によっては余裕が3mmしかない

```
墨貫入 9号   幅 32.5cm
スリム CB-SL-1 本体幅 32.8cm  → 差 0.3cm
```

9号対応をうたう8機種の本体幅は **32.8 〜 35.85cm**。9号土鍋の幅は **31 〜 32.5cm**。
**シリーズの選び方しだいで、余裕は0.3cmにも4.85cmにもなる。**

## ★ 発見3：卓上に必要な幅は号数で決まる

| 号数 | 幅（取手込）のレンジ | 号数×3cmとの差 |
|---|---|---|
| 6号 | 21〜22cm | +3〜4cm |
| 7号 | 24〜26.5cm | +3〜5.5cm |
| 8号 | 27〜29.5cm | +3〜5.5cm |
| 9号 | 31〜32.5cm | +4〜5.5cm |
| 10号 | 34〜36cm | +4〜6cm |
