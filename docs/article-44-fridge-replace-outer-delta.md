## 1. テーマの決め方

月曜分（洗濯機・冷蔵庫）から1本。2026-10-28 承認の改善案は、購入意図の高い型番別・条件別に寄せる。

候補のうち、既存と意図が重なるものは外した。

| 候補 | 扱い |
|---|---|
| 棚下に置ける縦型 | 既存 `/washer/vertical-lid-open-height/` が、フタ全開時の高さと吊戸棚の干渉をすでに扱っている |
| 640パン対応ドラムの一覧 | 既存 `/washer/drum-waterproof-pan-fit/` と `/washer/lixil-panasonic-pan-inner-depth/` |
| 冷蔵庫の放熱スペース | 既存の据付奥行・左右上方あきと重なる |
| 型番別の置ける／置けない（置き場の上限） | 記事41が幅×奥行の上限で実施済み |
| かさ上げ台と排水口 | 台の一次が品番に分散する。今回は見送り |
| 買い替え前後の寸法差 | **採用**。公式が「従来品」と型番を書いた組だけを、幅・奥行・高さの差で判定する |

本記事の問いは「旧型の外形の箱に、公式が後継と書いた新型の外形が入るか。入らないとき、何mm、どの軸か」。扉の開放・横張り出し・搬入経路・置き場の絶対上限は判定に入れず、各記事へリンクした。

クーラーボックスは増やしていない。新カテゴリは作っていない。

## 2. データ源（一次・2026-11-09）

組は、メーカーが従来品の型番を書いた文があるものだけ。仕様ページの外形は幅×奥行×高さ（mm）。

| 新型 | 従来品 | 新型の外形 | 従来品の外形 | 結び |
|---|---|---|---|---|
| NR-F55HY2 | NR-F53HX1 | 650×699×1850 | 650×699×1828 | プレス注記。仕様ページも同値。内容積551Lと525L。据付奥行はどちらも699 |
| NR-F49EY3 | NR-F50EX1 | 650×650×1850 | 650×699×1828 | 製品ページが2024年度の従来品と明記。内容積490Lと501L。据付奥行650と699 |
| NR-E45RY3 | NR-E45PX1 | 600×648×1850 | 600×699×1828 | 同上。内容積はどちらも450L。据付奥行648と699 |
| NR-E41RY3 | NR-E41EX1 | 600×648×1850 | 600×679×1818 | 同上。内容積410Lと406L。据付奥行648と684 |
| MR-MZ60N | MR-MXD57G | 685×738×1833 | 685×738×1826 | 三菱の2026年度品の説明注記。内容積と据付奥行は注記に無い |

想定（当サイト。メーカー公表ではない）: 旧型の天面から上の障害物までの空き 10／25／40mm。

製品ページの cm は、仕様の mm と一致する（65cm=650、69.9cm=699、64.8cm=648、67.9cm=679、185cm=1850、182.8cm=1828、181.8cm=1818）。

末尾世代で外形が一致し、従来品とは書かれていなかったので○×から外したもの: NR-F55WX2 と NR-F55WX3（どちらも685×699×1828）、NR-F55HY2 と NR-F55HY3（どちらも650×699×1850）。

## 4. 未検証・未掲載

- 実キッチンの天面から吊戸棚までの距離
- 従来品4機種の仕様ページに「上方向に40mm以上」が無いこと。新旧で必要な上方あきが同じかは未検証
- 三菱の奥行738mmがドア角までか脚カバー込みか（注記に但し書き無し）
- 三菱 MR-MXD57G の個別仕様ページ（比較注記以外）
- 三菱の定格内容積の差（注記に無い）
- 東芝・日立・シャープで、従来品の型番と外形が同じ文にある組（東芝カタログPDFは文字が取れず、仕様ページだけでは組を結べなかった）
- 品番の末尾だけが違う組を後継とみなすこと（外形が一致した例は○×に未使用）
- Amazon直リンクは **Panasonic NR-E45RY3L-S** だけ。2026-11-09 に `https://www.amazon.co.jp/dp/B0G63M3YDZ` を開き、Model Number NR-E45RY3L-S と「64.8D x 60W x 185H cm」、容量450Lを確認した。左開き。Amazon表記の冷凍室容量は公式の93Lと一致しないので、記事の数字には使っていない。NR-F55HY2・NR-F49EY3・NR-E41RY3・MR-MZ60N は、同じ型番の商品ページで寸法まで確認できなかった
