# 記事02：クーラーボックスに2Lペットボトルは立てて入るか

作成日: 2026-08-24 ／ ステータス: **公開済み**（`/coolerbox/2l-tateru/`）

記事01（500mlは何本）で集めたクーラーボックスの内寸を、**追加取材ゼロで再利用**した2本目。
新たに取ったのは大型ペットボトルの寸法だけ。

## なぜ350ml缶ではなくこちらを先に書いたか

当初は記事02を「350ml缶は何本入るか」にする予定だったが、**缶の寸法の一次情報が取れなかった。**

| 当たった先 | 結果 |
|---|---|
| 大和製罐「2ピース飲料缶」 | 容量（135/190/250/350/500ml）のみ。**寸法表なし** |
| 武内プレス工業「飲料缶」 | 「φ53（135ml）〜φ76.5（750ml）」という**範囲のみ** |
| 東洋製罐 | 食缶の一覧はあるが飲料缶の寸法表は未発見 |

「350ml缶＝66φ×122mm」は多くの二次情報が書いているが、**製缶メーカーの公表値としては確認できていない。**
`未検証` のまま記事にはできないので、**2Lを先に書いた。** 缶は一次情報が取れ次第。

## ★ 記事の核になる発見（4つ）

### ① 2Lが立つのは8製品中1つだけ

深さ310mmのアイリス HUGEL 40L のみ。**余裕は4mm。**
10〜25Lクラス（深さ220〜255mm）は全滅。

### ② 1.5Lは2Lとほぼ同じ高さ。1.5L角は2Lより高い

```
1.5L角        307.5mm  ← 最も高い
2L角ボトル(A) 306mm
2L角ボトル(B) 305mm ／ 1.5L炭酸 305mm
```

**「2Lが無理でも1.5Lなら」は成り立たない。** 1.5Lは細くなっているだけで背は変わらない。
例外は 1.5L平角（285mm）のみ。

### ③ 1Lでも立たないことがある

**1L炭酸は260.6mm**で、25Lクラス（深さ255mm）でも立たない。
炭酸ボトルは圧力に耐えるため丸く細長い。
深さ220mmのモデル（ダイワ10L・20L）は**1Lですら1本も立たない。**

### ④ 寝かせても入らない製品がある

| 製品 | 最長辺 | 2L(306mm) |
|---|---|---|
| ダイワ S1000X（10L） | 260mm | **入らない** |
| アイリス HUGEL 15L | 302mm | **入らない**（4mm差） |

**容量Lは深さと相関しない。** ダイワ S1000X（10L）と S2000（20L）は**深さが同じ220mm**で、
20Lは横に広がっただけ。

## 判定の基準

```
2L・1.5L を立てる   → 内寸の深さ 310mm 以上
1L（炭酸含む）      → 265mm 以上
1L（角型のみ）      → 230mm 以上
```
