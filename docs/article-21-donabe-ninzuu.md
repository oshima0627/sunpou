## 2. 結論と検算

### 号数が決めているもの／いないもの

| | 号数内のばらつき |
|---|---|
| **口径** | **最大1cm**（8号の24〜25cm）。7号と10号は全製品が同じ値 |
| 幅（取手込） | 9号で31〜32.5cm |
| 高さ | 9号で15〜17cm |
| **容量** | **9号で2.2〜3.2ℓ＝1.45倍** |
| **目安人数** | **9号で「2〜3人前」と「4〜5人前」** |

### 1人あたり容量（当サイトの計算）

`容量 ÷ 目安人数の多いほう`

- **8号以上の10製品はすべて 0.60〜0.75ℓ。中央値 0.67ℓ**
- 7号以下の8製品は 0.40〜1.00ℓ（1人前・1〜2人前に丸められるため）

→ 記事で出した逆算ルール：**必要な容量 ＝ 人数 × 0.7ℓ**
**18製品すべてで、公表の目安人数の範囲に0.5人以内で収まった。**

### 号数の逆転

- 墨貫入 10号 2.9ℓ・3〜4人前 **＜** 花三島 9号 3.2ℓ・4〜5人前
- 墨貫入 10号 2.9ℓ **＜** 菊花深型 9号 3.0ℓ・4〜5人前
- 花三島 8号 と 墨貫入 9号 は **どちらも 2.2ℓ・2〜3人前**（完全一致）
- 花三島 7号 と 墨貫入 8号 は **どちらも 1.5ℓ・1〜2人前**（完全一致）

### 円筒との比

`π×(口径/2)²×高さ` に対する公表容量の割合。**シリーズで割合そのものが違う**。

- 花三島 29〜32% ／ 菊花 27〜32% ／ 墨貫入 22〜24%
- → **口径と高さを掛けても容量は出せない**

### 検算（2026-09-07）

**記事の計算値33件を、元JSONから独立に再計算して全件一致を確認した。**
1人あたり容量10件／容量÷0.7が6件／円筒と割合10件／1.45倍／号数ごとのレンジ6件。
