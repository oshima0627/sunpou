# SERP 目視チェック（2026-08-24）

判定基準は **「検索1ページ目（上位10位以内）に個人サイトが入っているか」**。
個人が入れている＝新規の個人サイトにも勝てる余地がある、という読み方。

## 検証方法と、その限界

`検証済み` — Google（google.co.jp）で13キーワードを実際に検索し、
オーガニック結果の**ドメインとタイトルを上位8〜12件まで読んだ。**

`未検証` — 以下2点は推論なので、断定していない。

1. **「個人サイトかどうか」はドメイン名と記事タイトルからの判断。** 各サイトを開いて運営者情報を
   確認したわけではない。`note.com` `hatenablog.com` は個人と見なした
2. **利用者のログイン済み Chrome で検索したため、結果がパーソナライズ・地域補正されている可能性がある。**
   厳密にやるならシークレットウィンドウか順位計測ツールで再確認が必要

## ★ 導かれたルール — 勝てるキーワードは2種類しかない

| | 型 | なぜそうなるか |
|---|---|---|
| ✗ | **サイズ・容量・型番**（40L／幅90cm／200g／195/65R15） | 楽天・Amazon・価格.com の商品一覧ページが構造的に強い。**記事では勝てない** |
| ✗ | **規格・等級の説明**（遮光1級2級／クロス・マイクロカット／SGマーク） | メーカー・専門小売・公的機関が権威を持つ。**「解説」は勝ち目がない** |
| ✗ | **公的な規定**（航空会社の手荷物サイズ） | 一次情報の保有者（ANA・JAL）が独占。**原理的に抜けない** |
| **○** | **メーカーをまたぐ横断比較**（テプラ vs ピータッチ vs ネームランド） | **1社では書けない。** メーカーも専門店も自社製品しか語らないので、個人が入れる |
| **○** | **カタログに載っていない実測値・累計コスト**（ランニングコスト／500mlが何本入るか） | **買って測った人しか書けない。** 知恵袋が上位に来ているのは「まともな答えが無い」サイン |

### ⚠️ README のジャンル選定条件と食い違っている

README はジャンル選定条件の①に
**「用途が決まっていて、選ぶ基準が数値やサイズで比べられる」**
を挙げているが、**サイズと規格は、まさに個人が勝てない領域だった。**

**「数値で決着がつく」のうち勝てるのは、カタログに載っていない数値だけ。**
つまり **実測値**（実際に入れて数えた・測った）と **累計コスト**（1年使うといくら）。

→ 条件①は「数値で比べられる」ではなく
**「メーカーをまたいで比べる必要がある、またはカタログに無い数値で決まる」**に置き換えるべき。
（これは判断が要るので、README はまだ書き換えていない）

## ⚠️ もっと重要な問題：報酬額と勝ち目が逆相関している

第1節（`affiliate-program-facts.md`）で出した「単価 × 料率」の順位と、上の判定を並べると：

| ジャンル | 1件の報酬 | SERP 判定 |
|---|---|---|
| 機内持ち込みスーツケース | **960円**（1位） | **✗ 勝ち目なし**（EC独占＋航空会社公式） |
| 家庭用シュレッダー | 360円（2位） | △〜✗（専門小売のコラムが強い） |
| 軽量折りたたみ傘 | 320円（3位） | **✗ 勝ち目なし**（EC・ブランド独占） |
| ベビーゲート | 320円（3位） | △ |
| **おむつ用ゴミ箱** | 240円 | **○★ 個人5件** |
| **ラベルライター** | 240円 | **○★ 個人4件**（テプラvsピータッチ） |
| **クーラーボックス** | 240円 | ○ |
| 双眼鏡 | 160円 | △ |

**報酬額の上位3件が、SERP では最も勝ち目がない。**
勝てるのは報酬240円の中位帯。**「高単価に寄せる」戦略は、この15件では成立しない。**

### 現時点での結論（仮）

**着手するなら、報酬額ではなく SERP の勝ち目で選ぶ。優先順位はこの3つ。**

1. **おむつ用ゴミ箱** — ランニングコストの実測比較。個人5件が入れており、需要も継続的（新生児期は毎年発生）
2. **ラベルライター** — テプラ／ピータッチ／ネームランドの横断比較＋テープの累計コスト
3. **クーラーボックス** — 「20Lに500mlが何本入るか」の実測。知恵袋が1位＝まともな記事が無い

いずれも **報酬240円**。**月1万円なら月42件、月3万円なら月125件**が必要。
→ 収益モデルの再設計（`affiliate-program-facts.md` の「次にやること」3番）は**まだ解けていない。**
