## ★ 導かれたルール — 勝てるキーワードは2種類しかない

| | 型 | なぜそうなるか |
|---|---|---|
| ✗ | **サイズ・容量・型番**（40L／幅90cm／200g／195/65R15） | 楽天・Amazon・価格.com の商品一覧ページが構造的に強い。**記事では勝てない** |
| ✗ | **規格・等級の説明**（遮光1級2級／クロス・マイクロカット／SGマーク） | メーカー・専門小売・公的機関が権威を持つ。**「解説」は勝ち目がない** |
| ✗ | **公的な規定**（航空会社の手荷物サイズ） | 一次情報の保有者（ANA・JAL）が独占。**原理的に抜けない** |
| **○** | **メーカーをまたぐ横断比較**（テプラ vs ピータッチ vs ネームランド） | **1社では書けない。** メーカーも専門店も自社製品しか語らないので、個人が入れる |
| **○** | **カタログに載っていない実測値・累計コスト**（ランニングコスト／500mlが何本入るか） | **買って測った人しか書けない。** 知恵袋が上位に来ているのは「まともな答えが無い」サイン |

### ⚠️ README のジャンル選定条件と食い違っている

README はジャンル選定条件の①に
**「用途が決まっていて、選ぶ基準が数値やサイズで比べられる」**
を挙げているが、**サイズと規格は、まさに個人が勝てない領域だった。**

**「数値で決着がつく」のうち勝てるのは、カタログに載っていない数値だけ。**
つまり **実測値**（実際に入れて数えた・測った）と **累計コスト**（1年使うといくら）。

→ 条件①は「数値で比べられる」ではなく
**「メーカーをまたいで比べる必要がある、またはカタログに無い数値で決まる」**に置き換えるべき。
（これは判断が要るので、README はまだ書き換えていない）

### ★ これを「需要なし」と読むのは誤り

**Google のオートコンプリートで反証した。** サジェストは実際に検索されているクエリしか出さない。

`検証済み` — Google のサジェストAPI（`/complete/search`）を引いた結果：

```
「テプラ ピータッチ」のサジェスト
  → テプラ ピータッチキューブ / テプラ ピータッチ 比較 /
    テプラ ピータッチ ネームランド 比較 / テプラ ピータッチキューブ 比較 /
    ★テプラ ピータッチ 違い★ / テプラ ピータッチ テープ 比較 / …
```

**「テプラ ピータッチ 違い」はサジェストに出る。** つまり実需はある。
→ **aramakijake は複合キーワードのデータを持っていない。0 はデータ欠損。**

⚠️ **教訓：無料ツールの「0」を検証済みの事実として扱わないこと。**
ロングテールの需要の有無は、**サジェストに出るかどうか**で見るほうが信頼できる
（ただし**絶対値は分からない**。数値が欲しいならキーワードプランナー＝Google Ads アカウントが必要）。

# 収益モデルの試算

`未検証` — 以下は**仮定を3つ積んだ試算**。実測ではない。
1. 1位のCTR ≒ 42%（aramakijake のモデル値をそのまま使用）
2. 記事から Amazon リンクへのクリック率 20%
3. Amazon の購入率 5%（クリック→24時間以内）

→ **1セッションあたりの成果 = 0.20 × 0.05 = 1%**。報酬240円なら **1セッション ≒ 2.4円**。

| 記事の想定 | 1位時のセッション/月 | 成果件数 | **月の報酬** |
|---|---|---|---|
| ヘッドKWで1位（例：おむつ ゴミ箱） | 7,656 | 77件 | **18,000円** ← ただし**このKWは勝てない** |
| 中間KWで1位（例：おむつ ゴミ箱 臭わない） | 804 | 8件 | **1,900円** |
| ロングテールで1位（例：クーラーボックス 20l） | 250 | 2.5件 | **600円** |

## ★ 結論：勝てるKWは、1記事あたり月500〜2,000円

**ヘッドKWは報酬が大きいが勝てない。勝てるロングテールは1記事500〜2,000円。**

```
月1万円 →  5〜20記事が1位を取れている状態
月3万円 → 15〜60記事が1位を取れている状態
```

⚠️ **「1位を取れている」が前提。** 公開してすぐには順位が付かない
（`affiliate-program-facts.md` の出典記事いわく、順位がつくまで数週間〜数ヶ月）。

→ これが**リベの型が「ブログは成果が出るまで遅い」と言っている中身**。
ASP案件（1件2,000円）なら1記事で同じ収益に届くところ、**Amazon単体では記事数で埋めるしかない。**

## 未検証で残っている、最も効く数字

**リンククリック率と購入率（上の仮定2・3）が、結論を丸ごと動かす。**
購入率が5%ではなく2%なら、収益は2/5になり「月1万円に13〜50記事」になる。

→ **これは自分の記事で実測するしかない。** 最初の数記事は
「収益を出す」より **「クリック率と購入率を測る」** ことが目的になる。

## 次にやること

1. **最初の1記事を書くジャンルを決める。** 現時点の推しは **クーラーボックス「500ml 何本」**。
   理由＝サジェストが本数バリエーションで埋まっており（需要が構造的）、
   知恵袋が1位（まともな記事が無い）、かつ**実測すれば誰も持っていないデータになる**
2. 検索数の絶対値が必要なら **Google Ads アカウントでキーワードプランナー**を使う
   （アカウント作成は利用者ご本人の作業）
3. 上位3ジャンルの SERP を、**シークレットウィンドウで再確認**してパーソナライズの影響を排除する
4. 個人サイトと判定したドメインを実際に開き、**運営者情報と記事の作り込み度**を確認する
   （「個人だが法人並みに作り込まれている」なら勝ち目の判定は変わる）
