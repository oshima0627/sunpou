# 記事05：ダイワとシマノのクーラーボックスを寸法で比べる

作成日: 2026-08-24 ／ ステータス: **公開済み**（`/coolerbox/daiwa-shimano/`）

## このテーマにした理由

### 需要（Googleサジェスト・実取得）

```
「ダイワ シマノ クーラーボックス」
  → ★比較★ / ★どっちがいい★ / ★保冷力★ / ★どっち★ / おすすめ /
    シマノ ダイワ クーラーボックス 比較 保冷力 / キス釣り どっち / 最強
```

**`docs/serp-check.md` が ○★ と判定した「テプラ ピータッチ 違い」と同じ形。**
**メーカー横断比較＝1社では書けない。** サジェストが「比較／どっち／どっちがいい」で埋まっている。

### 記事04までで足りていなかったもの

記事01〜04はダイワ・ロゴス・アイリスオーヤマ・キャプテンスタッグの4社だけだった。
**検索需要のあるシマノが抜けていた。**

⚠️ サジェストの主要な意図は**保冷力**で、これは寸法では答えられない。
→ **保冷力を評価するのではなく、「両社の表示が同じ物差しかどうか」という事実だけを扱う**方針にした。
結果として**同じ物差しだった**ので、そのまま並べれば読者が自分で比べられる。

## ② シマノ『COOL』の定義（原文）

> **JIS簡便法による測定とは？** 外気40℃に調整された恒温室内に、クーラーボックス本体容量の25％に
> 相当する角氷を入れたクーラーボックスを放置。8時間後に氷の重量を測定して氷の残存率を算出します。
>
> **シマノの新保冷力基準『COOL』とは？** …氷の残存率から、残存率が0％になるまでの時間を計算して、
> 「COOL○○」という値で表示しています。
>
> ※保冷力表記は、当社独自のテストによる目安値であり、保証値ではありません。

## ③ ダイワ『KEEP』の定義（原文）

出典：[シークールキャリー II 製品ページ](https://www.daiwa.com/jp/product/qmajshz)

> **ダイワクーラーの新たな指標『KEEP』**
> クーラーボックスにとって重要なのはズバリ、氷の保ち時間！ ダイワはこの指標を「KEEP○○」と表現した。
> 『KEEP』は**JIS規格（JIS S 2048：2006）の簡便法**に基づいて氷の残存率を算出。
> 更に氷が溶けきるまでの時間に換算して「KEEP○○」という値で表現している。
>
> **【JIS簡便法による測定とは？】** 外気40℃に調整された恒温室内に、クーラーボックス本体容量の25％に
> 相当する角氷を入れたクーラーボックスを放置。8時間後に氷の重量を測定して氷の残存率を算出。
>
> **【KEEP換算とは？】** その氷の残存率から、残存率が0％になるまでの時間を計算して、
> 「KEEP○○」という値で表示している。
>
> ※保冷表示の値はあくまで保冷力の目安であり、実際の保冷時間とは異なる。

### ★ KEEP と COOL は、同じ定義

```
測定  外気40℃／本体容量の25%の角氷／8時間後の残存率      ← 両社とも同じ
換算  残存率が0%になるまでの時間                         ← 両社とも同じ
根拠  JIS S 2048：2006 の簡便法                          ← ダイワが規格番号まで明記
```

**名前が違うだけで、同じ物差し。単位は時間。** → **並べて比べられる。**

⚠️ **記事03・04で「単位も試験条件もばらばらで比べられない」と書いたのは、
ダイワ・アイリスオーヤマ・ロゴスの3社について。** その3社については今も正しい。
**シマノを入れると、ダイワとシマノだけは比べられる**という話になる。

⚠️ **アイリスオーヤマの「保冷日数」は別物。** 記事04で引用したとおり
**容量比40%の氷・30℃9h/20℃15h**で、JIS簡便法（25%の氷・外気40℃）とは条件が違う。**換算できない。**

## ④ ダイワのその他の注記（[シークールキャリー II](https://www.daiwa.com/jp/product/qmajshz)）

> ※内寸は一番狭い所、外寸は一番広い所で、キャリーハンドル（縮めた状態）を含みます。
> ※**サイズ表示は縦（奥行）×幅×高さです。**
> ※ペットボトルのサイズにはバラつきがありますので**収納可能数は目安です。**
> ※板氷のサイズ（mm） … 約250×130×65

**「サイズ表示は縦（奥行）×幅×高さ」** ＝ 記事01〜04で `17×26×22` を「幅×奥行×深さ」と読んでいたが、
**正しくは「奥行×幅×高さ」。** 床の本数計算では最初の2つが入れ替わるだけなので**計算結果は変わらない。**

# 検証：計算結果

計算スクリプトは `scratchpad/ds.py`。**シマノが公表している前提ボトル Φ66×207mm で両社を数え直した。**
シマノは**底部の内寸**、ダイワは**一番狭い所の内寸**を使う（どちらも「いちばん狭い床」の意味）。

### ★ 3つの発見

1. **ダイワ20L と シマノ22L は、どちらも15本。** 内寸は 22×39cm と 21.1×39.1cm でほぼ同じ床
2. **ダイワ25L と シマノ30L も、どちらも18本。** 公表容量は5L違うのに本数は同じ
3. **ダイワの公表18本と計算15本の差3本は、箱の差ではなくボトルの前提の差。**
   ダイワ自身が「ペットボトルのサイズにはバラつきがありますので収納可能数は目安です」と注記している

## 断熱グレードを上げたときに変わるもの

**内寸も外寸も変わらない。増えるのは重さだけ。** 記事04でダイワについて見つけたパターンが、**シマノでも同じ。**

| 製品 | 保冷力の表示 | 重量 |
|---|---|---|
| シマノ 9L | COOL 32 → 49 | 1.7 → 1.9kg（1.12倍） |
| シマノ 17L | COOL 51 → 105 | 3.4 → 5.1kg（1.50倍） |
| シマノ 30L | COOL 70 → 140 | 4.8 → 7.7kg（1.60倍） |
| ダイワ 1000X | KEEP 26 → 55 | 2.1 → 2.6kg（1.24倍） |
| ダイワ 2000 | KEEP 46 → 80 | 3.7 → 4.8kg（1.30倍） |
| ダイワ 2500 | KEEP 56 → 90 | 4.3 → 5.5kg（1.28倍） |

**保冷力の表示は約2倍になるのに、重さは1.1〜1.6倍。** 内寸は1mmも変わらない。
