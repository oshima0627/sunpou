## 1. テーマの決め方

木曜分（アウトドア）。購入意図の高い型番別・条件別に寄せる。

候補のうち、既存と意図が重なるものは外した。

| 候補 | 扱い |
|---|---|
| ペットボトルが何本立つか | 既存のクーラーボックス記事（500ml・2L）と重なる |
| 鍋・五徳とコンロ | 既存のカセットコンロ・土鍋と重なる |
| ポータブル電源の外形と車載 | 車の荷室寸法が箱として揃うかを先に見る必要があり、今回は見送り |
| キャリーワゴンの積載と車載 | 同上。折りたたみ寸法だけでは荷室の一次が足りない |
| チェア座面高とテーブル高 | 一次は取れる。今回は床とマットの○×を優先 |
| 焚き火台と薪の長さ | 薪の規格がメーカー一次で揃うかを未確認。見送り |
| テント・寝袋・マットの収納サイズ | 3種の収納を足す問いは残る。今回は寝られる枚数を優先 |
| テント床とマット幅 | **採用**。定員の人数と、公表の床に軸平行で並ぶ枚数は別 |

本記事の問いは「公表のインナー床の2辺に、幅50×長さ150、幅60×長さ180、幅80×長さ208のマットが何枚置けるか。その枚数は定員の下限に届くか」。

## 3. 検算

`python3 tools/check-article-43.py`

向きは、マットの長さが収まる辺だけ。両方できるときは枚数が多い方。同数なら幅方向の余りが大きい方。軸に平行、全部同じ向き、重ねない。

| マット | 定員がある10機種で、下限に届く向きがある | 多い向きでも届かない |
|---|---|---|
| 幅50×長さ150 | 10 | 0 |
| 幅60×長さ180 | 9 | 1（T5-689-TN。4枚と3枚。定員5） |
| 幅80×長さ208 | 1（T3-44-TN。多い向き3枚、少ない向き2枚） | 9 |

T2-629-TN / T2-275 は床225×145。長さ150以上は145側に置けない。幅60cmは2枚、余り25cm。幅80cmは1枚、余り65cm。

71201192（210×210、3〜4人）は幅50cmで4枚（余り10cm）、幅60cmで3枚（余り30cm）。正方形なので向きで枚数は変わらない。

カマボコ3M（280×220）に、キワミエアーLを2枚（幅276、余り4cm）または M+S+S（幅275、余り5cm）。長さ208は220側で余り12cm。ページの「ぴったり」が余り0を指すかは未検証。エアーでないキワミの寸法が同じかも未検証。

## 4. 未検証・未掲載

- 地面に敷いた適合。各社が「約」「若干の個体差」と書いている差の大きさ
- 各社の床の測り方が同じか
- 壁の傾斜、ドアのあけしろ、荷物、斜め置き、頭の互い違い
- ソトネノサソイの接合5〜6cmを除いた寝面（幅60cmの条件には使っていない）
- エアーでないソトネノキワミの寸法
- ロゴス3機種の定員（仕様ブロックに人数が無い）
- コールマン4Sの360と240のどちらが入口か
- Amazon直リンクは載せていない。T2-629 はブラック（T2-629-BK）の商品ページしか寸法一致を確認できず、記事のタン（T2-629-TN）とは色が違う。T5-689-TN のページは中古出品の文言が混ざり、新品の型番ページとして採用していない
