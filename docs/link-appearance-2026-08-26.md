`検証済み` — コード・原稿・本番DOM・アソシエイト・セントラル・規約原文を実際に見て確認した。

## 結論

1. **`.buy` のCSSが1行も存在しない。** ビルドはクラスを付けているのにスタイル定義が無く、
   **Amazonへのリンクが記事内リンクと完全に同じ見た目**（`#0077c6`・太字・下線）で出ている。
2. **商品画像も価格も使えない。** 規約上 Creators API 経由でしか取得できず、
   その API は**「過去30日間に適格販売10件」**が条件。現在0件。
3. **SiteStripe も URL のコピーだけ**になっていて、画像リンク・ウィジェットの選択肢が無い。

→ **「いい感じ」は自前のデザインで作るしかない。** 逆に言えば、規約待ちの要素はひとつも無い。


## 2. 規約で確定したこと（原文をcurlで取得してgrepした）

出典: `https://affiliate.amazon.co.jp/help/operating/policies`（2026-08-26 取得・HTTP 200）

### 商品画像 → Creators API 経由のみ

> Creators APIまたはデータフィードを利用することにより、乙は、１つまたは複数のAmazonの関連サイトで
> 提供される商品に関する**データ、画像、テキスト**その他の情報およびコンテンツにアクセスすることができます。

> また、**アマゾン・サイト以外のサイトで提供されたいかなるデータ、画像、テキスト**その他の情報または
> コンテンツも、「プロダクト広告コンテンツ」には**含まれません。**

> (h) 乙は、**画像で構成されるプロダクト広告コンテンツを保存またはキャッシュしてはいけません**が、
> 画像で構成されるプロダクト広告コンテンツへのリンクについては最長24時間保存することができます。

### 価格・在庫 → Amazon提供のリンクか Creators API のみ

> 乙のサイトでは、以下の場合に限り、価格および在庫を表示できるものとします。
> **(a)甲が価格および在庫のデータを表示しているリンクを提供する場合、または(b)乙がCreators APIを経由して
> 商品の価格および在庫のデータを取得し**、本ライセンスに定めるCreators APIの使用に関する要件を遵守する場合。

### その Creators API / PA-API が使えるか → **使えない**

アソシエイト・セントラルの Product Advertising API ページ（2026-08-26 実機確認）。
3条件すべてに **❌** が付いていた:

> ❌ 承認されたアソシエイトアカウントを持つ。
> ❌ Amazonアソシエイトプログラム運営契約を遵守する。
> ❌ **PA APIへのアクセスを取得し、PA APIを呼び出す機能を維持するには、過去30日間に条件を満たす売上を10件有する必要があります。**

⚠️ **審査合格に必要な「180日で3件」より厳しい「30日で10件」。** 画像はかなり先の話。
同ページに「PAAPI が Creators API で利用できるようになりました」とあり、入口は Creators API に一本化されている。

### SiteStripe（アソシエイト・ツールバー）

実機で `リンク生成` を押して確認。出るのは **ストアID／追跡番号の選択と、ショートリンク／完全なリンクのコピーだけ。**
**画像リンク・テキスト＋画像・ウィジェットの選択肢は無い。**

## 4. できること（推奨順）

規約の制約は「画像・価格」だけで、**下の4つはどれも今すぐできる。**

| # | 打ち手 | 触る場所 | 効き方 |
|---|---|---|---|
| **A** | **`.buy` に専用スタイルを付ける** | `styles.css` のみ | いちばん小さく、いちばん確実。いまゼロなので伸びしろが大きい |
| **B** | **リンク文言の二重表示をやめる** | `build.mjs` ＋ 原稿89箇所 | 最大130文字のセルが半分以下になる。表が読めるようになる |
| **C** | **収益記事に自前の「製品カード」を置く** | `build.mjs` ＋ `styles.css` ＋ 原稿 | 表の外に押せる場所を作る。画像なしでも自分の計算値が主役になる |
| **D** | **検索語を調整して着地を良くする** | 原稿の `[[LINK:...]]` | 見た目ではないが「いい感じ」に直結。要・全件確認 |

**A→B の順を勧める。** A はCSSだけで完結し、B は「良い書き方が既に脚立の記事にある」ので手本がある。
C は形が大きく、D は324本の確認が要るので、**A・B の効果を測ってから**が筋。

⚠️ **効果は測れる。** 分母は Cloudflare のページビュー、分子はアソシエイトのクリック数。
ただし **記事がまだ1本もインデックスされていない**ので（`docs/measurement-2026-08-26.md`）、
**いま変えても当分は自分のアクセスしか分母に入らない。** 見た目を直すこと自体は損にならないが、
**「変えたら増えた」と言えるようになるのはインデックス後。**
