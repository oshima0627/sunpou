# 記事17 カセットボンベの備蓄本数 — データ源と検算

公開: `/cassette-konro/bombe-honsuu/`（2026-08-25）
**カセットコンロの2本目。** これでこのカテゴリは2本になった。

## なぜこのテーマにしたか

サジェスト `カセットボンベ 何本` が**防災の文脈で濃かった**：
何本まで／**何本必要**／**何本備蓄**／**非常用 何本**／キャンプ 何本／**災害時 何本**／**備蓄 何本**／**防災 何本**

`カセットコンロ 何分` も：何分もつ／一本 何分／ボンベ1本 何分

**季節に依存しない**（鍋シーズンに縛られない）のが決め手。単価は120円で最下位のままだが、
**3件の適格販売を取るには単価より件数**という判断。

## ★ この記事の核心

**農水省とイワタニは、そのままでは突き合わせられない。**

| | 単位 |
|---|---|
| 農林水産省 | **1人・1週間** で「約6本」 |
| 岩谷産業 | **2人分・1日3回・用途ごと** の消費ガス量（g） |

しかも **イワタニの表には合計が書かれていない。**
→ **足して1人・1週間に直すと、6本に届くのは「10℃で全部の用途をまかなうとき」だけだった。**

> ガスの気化および沸き上がり時間は気温によって大きな影響を受けるため、必要な本数が変わります

### 岩谷産業 使用期限のページ
https://www.iwatani.co.jp/jpn/consumer/products/cg/useful/bombe/

- **カセットこんろ：製造から10年を目安に買い替え**
- **カセットボンベ：製造から約7年以内の使い切りが目安**
- 製造年月日は**缶底の数字**で確認。**缶底のアルファベットは製造年月日と関係ない（Hは平成ではない）**
- ローリングストック法を推奨

**農水省の「ボンベ7年・コンロ10年」と完全に一致。** 省庁とメーカーで裏が取れた。

## 計算（`site/content/articles/` の値と一致することを検算済み）

```
1人1週間の本数 ＝ Σ(用途の1日3回ぶんの消費g) × 7日 ÷ 250g ÷ 2人
```

| 使い方（2人分・1日3回） | 25℃ | 10℃ | 1人1週間 25℃ | 1人1週間 10℃ |
|---|---|---|---|---|
| 食事＋カップ麺＋飲み物＋お湯 | 289.2g | 415.2g | **4.0本** | **5.8本** |
| 食事＋飲み物＋お湯 | 230.1g | 320.7g | 3.2本 | 4.5本 |
| 食事＋飲み物 | 171.0g | 226.2g | 2.4本 | 3.2本 |
| 食事だけ | 141.6g | 179.1g | 2.0本 | 2.5本 |

**気温の倍率**：食事（強火＋中火）1.26倍／カップ麺・飲み物・お湯（強火のみ）1.60倍
→ **中火の時間は気温で変わらないぶん、影響が薄まる。**

## ⚠️ 検算スクリプトが誤りを1件見つけた

**記事に「4.1本」と書いていたが、正しくは 4.0本。**
`289.2 × 7 ÷ 250 ÷ 2 = 4.0488` → 四捨五入して **4.0**。手計算で4.1と書いていた。

→ **数値を書いたら、必ずスクリプトで再計算して記事の値と突き合わせる。**
図版の aria-label にも同じ誤りが入っていたので、両方直した。

## 安全側に倒した書き方

計算では「6本は多め」に見えるが、**記事では減らす方向に誘導していない。**

- 「6本は多すぎるという話ではない」と明記
- 「備蓄は足りなかったときに買い足せない。少ないほうに寄せる理由がない」と明記
- 「迷うなら農水省の1人6本でよい」と結論

**防災の推奨値を下げる主張はしない。**

## 取得の手口（記録）

⚠️ **岩谷産業は curl が403。** ブラウザで `iwatani.co.jp` のタブを開いてから、
**ページ内で同期 XMLHttpRequest** を使うと他ページもまとめて取れる。

```js
const x = new XMLHttpRequest();
x.open('GET','https://www.iwatani.co.jp/jpn/consumer/products/cg/useful/stockpile/', false);
x.send();
// x.responseText を DOMParser に通すと table も読める
```

⚠️ **`navigate` で直接 URL を指定してもトップページにリダイレクトされた。** 上のXHRなら通る。
